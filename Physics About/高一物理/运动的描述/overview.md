# 运动的描述 — 全局视图：参考工具 × 描述过程

## 概述

本章解决一个核心问题：**怎么描述一个物体的机械运动？** 四个知识点由粗到精递进——先建立观察框架，再定义描述量，然后图像化呈现，最后实验验证。

| 视角 | y 轴 | x 轴 | 核心问题 |
|:---|:---|:---|:---|
| **读法 A** | 描述层次（H1→H4） | 描述过程（4阶段） | 各阶段从哪一层获取描述工具？ |
| **读法 B** | 物理量快照 | 描述过程（4阶段） | 各阶段产生什么物理量/结果？ |

> 读法 B 中 H1 参考框架 → H2 基本物理量 → H3 图像工具 → H4 实验验证 自底向上递推，上一层的结果是下一层的输入。

## 四节递进关系

```
质点与参考系 ──(建立框架)──→ 时间与位移 ──(定义描述量)──→ x-t图像 ──(可视化)──→ 打点计时器 ──(验证测量)
```

| 节 | 解决什么 | 产出 |
|:---|:---|:---|
| §1 质点与参考系 | 在哪观察？怎么简化？ | 参考系 + 质点 + 坐标系 + 位置 |
| §2 时间与位移 | 何时？变了多少？ | 时刻/时间间隔 + 路程/位移 |
| §3 位移-时间与图像 | 过程长什么样？ | x-t 图像，斜率→速度方向与快慢 |
| §4 打点计时器 | 真的吗？怎么测？ | 纸带→时间间隔 0.02s→位移→近似速度 |
