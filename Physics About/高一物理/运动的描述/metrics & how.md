# 运动的描述 — 操作方法 × 验证标准

## §1 质点与参考系

| 操作 | How | 验证标准 |
|------|-----|---------|
| 选参考系 | 描述运动前声明"以___为参考系"；默认以地面为参考系 | 给"一辆行驶的公交车"，以地面和以司机为参考系分别描述乘客的运动状态 |
| 判断能否视为质点 | ① 物体大小 << 运动范围；② 只关心平动不关心转动；③ 运动发生在比自身尺寸大得多的空间 | 火车过桥 ≠ 质点；火车从北京到上海 = 质点 |
| 建坐标系 | 选原点 → 定正方向 → 标单位长度 → 一维用数轴 | 以校门口为原点，向东为正，标出教学楼(-50m)和操场(100m) |
| 标位置 | 在坐标系中写坐标值，一维带正负号 | x_A = 3m, x_B = −2m |

## §2 时间与位移

| 操作 | How | 验证标准 |
|------|-----|---------|
| 区分时刻/时间间隔 | 时刻是点（5s末、第3s初）；时间间隔是段（前5s、第3s内） | 给时间轴标出"第2s末""前3s""第4s内" |
| 算位移 Δx | Δx = x₂ − x₁；带正负号；一维矢量 | x₁=3m, x₂=−2m → Δx = −5m（沿负方向移动5m） |
| 算路程 s | 沿运动轨迹逐段累加；标量，总为正 | 先向东5m再向西3m → s=8m, Δx=2m |
| 位移 vs 路程 | 直线单向运动：s = `|Δx|`；折返运动：s > `|Δx|` | 来回一圈回到起点 → Δx=0, s=周长 |

## §3 位移-时间与图像

| 操作 | How | 验证标准 |
|------|-----|---------|
| 描点画 x-t 图 | 横轴 t/s，纵轴 x/m；描(t,x)点 → 光滑连线 | 给 5 组(t,x)数据能正确描点并连线 |
| 读位置 | x-t 图上某时刻对应的纵坐标值 | t=3s 时 x=5m |
| 判断运动类型 | 水平线=静止；倾斜直线=匀速；曲线=变速 | 给不同形状的 x-t 图判断运动状态 |
| 判断运动方向 | 斜率>0→沿正方向；斜率<0→沿负方向 | 斜率为负 → 物体沿负方向运动 |
| 比较快慢 | 斜率绝对值越大 → 运动越快 | 两条x-t直线，斜率陡的物体快 |
| 求速度(斜率) | 选两点 (t₁,x₁)(t₂,x₂) → v = (x₂−x₁)/(t₂−t₁) | v = 2m/s；负方向 v = −2m/s |

## §4 打点计时器

| 操作 | How | 验证标准 |
|------|-----|---------|
| 算时间间隔 | 间隔数 = 点数 − 1；Δt = 间隔数 × 0.02s | 纸带 6 个点（含首尾）→ 5 个间隔 → Δt = 0.10s |
| 测位移 | 测量点间距离：起点到第 n 点 = n 段累计 | 起点→第5点距离 = 前5段之和 |
| 判断运动快慢 | 相邻点间距 ↑ → 加速；间距不变 → 匀速；间距 ↓ → 减速 | 给一条点间距逐渐增大的纸带 → 加速运动 |
| 算瞬时速度(近似) | v ≈ 相邻两点的位移 ÷ 0.02s | 点间距 4cm → v ≈ 0.04m/0.02s = 2m/s |
| 算平均速度 | v̄ = 总位移 ÷ 总时间（从起点到末点） | 起点到第5点距离 20cm，Δt=0.10s → v̄=2m/s |
| 用纸带画 x-t 图 | 以起点为原点，每个时刻 t 的位移为 x，描点连线 | 匀速纸带 → x-t 图为直线 |

## 自测清单

- [ ] 能判断物体能否视为质点（3 个条件都理解）
- [ ] 能区分时刻/时间间隔、位移/路程（各做 3 个情景判断）
- [ ] 能从数轴坐标正确算出带正负号的 Δx
- [ ] 能从 x-t 图像读出位置、判断运动方向和快慢
- [ ] 能从斜率算出速度（含负方向）
- [ ] 能从打点纸带判断加速/匀速/减速
- [ ] 能从纸带算 Δt、位移、近似瞬时速度
