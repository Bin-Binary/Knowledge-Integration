Skill：SVG 线稿稿纸风格适配
触发条件
当用户提供一个需要修改的 SVG 文件，并要求参考「玲龙线稿模板」风格进行适配/修复/重新生成时，激活此 Skill。

模板规格（LingLong-Style）
属性
值
画布	width="2400" height="1080" viewBox="0 0 2400 1080"
纸张底色	#e8e2d5（暖米色旧纸张）
网格线色	#c6c0b4，stroke-width="0.5"，间距 120px
网格范围	竖线 x:120~2280，横线 y:80~960

处理步骤
第一步：解析源 SVG
提取所有图形元素、文字、箭头、连接关系
提取核心知识/信息，丢弃冗余注释（如 [→xxx.md#xx]）
第二步：拆除不兼容项
❌ 移除 scale() / translate() 变换 → 改用绝对坐标
❌ 移除白色/彩色背景 <rect>（与纸张底色冲突）
❌ 移除 <pattern> 内部网格（与模板网格重叠）
❌ 移除 opacity 属性 → 用稳定色值替代
❌ 移除 <filter> / <feTurbulence> 等滤镜（平台兼容性）
❌ 移除外部 CSS / JavaScript 引用
第三步：重排版面
三栏布局撑满画布，避免左右大面积留白
左栏理论/输入 x:140~640，中栏映射/箭头 x:640~880，右栏实践/输出 x:880~2260
中间箭头带宽度 240px 左右，不宜过宽
底部说明区域与上方内容保持 30px+ 间距，不重叠
对齐原则：同层级元素左边缘对齐
第四步：统一色彩体系
禁止冷调正红（#d94452）→ 改用暖棕红 #b5654a
卡片填充：统一 #ece8db（暖灰，与纸张底色融合），或极浅对应色
边框/文字：降低饱和度，与纸张底色同属暖色系

标题 22~24px，层标题 14~16px，文档标题 13~14px
标签/参数内容 11~12px（最小不低于 10px）
底部说明 12~13px，行距 28~32px

第六步：简化内容
只保留核心知识，砍掉第二行解释性文字
底部说明每条一句话，不加边框（文字直接落在稿纸上）
箭头标签水平排列，不旋转
输出模板
质量检查清单
 无 scale() / translate() 变换
 无 opacity 属性
 无白色/彩色背景矩形遮挡纸张底色
 无 <pattern> 内部网格
 网格 stroke-width="0.5"
 无冷调正红，红色统一为暖棕红
 左右无明显大面积留白
 字体最小 ≥10px，正文 ≥11px
 底部说明无重叠、无多余边框
 同层级元素左对齐!
