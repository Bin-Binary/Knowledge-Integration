# AI 应用层 · 总览

> Vibe Coding：AI 发散覆盖可能性 → 人做取舍 → AI 拆解为可执行清单。

```
  需求澄清 → PRD生成 → 系统设计 → 代码生成 → 验收确认
  模块需求    需求文档   架构设计    代码+测试    验收报告
```

| 阶段 | 主调角色 | 核心产出 | 自检上限 |
|------|---------|---------|---------|
| 需求澄清 | 产品经理 | 模块需求表 | 3 轮 |
| PRD 生成 | 产品经理 | 产品需求文档 | 3 轮 |
| 系统设计 | 架构师 | 架构+DB+API+项目结构 | 3 轮 |
| 代码生成 | 架构师+测试经理 | 代码+单元测试 | 3 轮 |
| 验收确认 | 测试经理 | 验收报告 | 3 轮 |

| 议题等级 | 触发条件 | 评审范围 |
|---------|---------|---------|
| L0 | 单模块、无跨模块 | 主调角色自行收敛 |
| L1 | 单模块、行为重构 | 主调全量 + 辅调关注点 |
| L2 | 多模块交互 | 四角色全量 |
| L3 | 架构级变更 | L2 + 评审专家一票否决 |

> [vibe-coding/vibecoding.md](./vibe-coding/docs/vibecoding.md) — 完整工作流规范。
