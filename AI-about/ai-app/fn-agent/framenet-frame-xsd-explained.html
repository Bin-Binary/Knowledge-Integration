FrameNet frame.xsd

用最简单的方式，讲清楚 FrameNet 的 Frame 数据结构设计

Frame (框架)

根节点 ID / name / cDate / cBy

一个 Frame 描述一个人类认知场景，比如"复仇"、"买卖"、"做饭"。它是整个 XSD 的根元素，所有 FE、lexUnit 都挂在 Frame 下面。

FE (框架元素)

角色 Core / Peripheral / Extra-Thematic

FE 是一个 Frame 中的参与者角色。比如"复仇"里的 Avenger（复仇者）、Offender（犯错者）、Injury（伤害）。可分为核心/外围/额外三类。

lexUnit (词汇单元)

词 avenge.v / revenge.n

lexUnit = 词 + 词性。它将具体的单词"锚定"到 Frame 上，告诉系统"avenge 这个动词属于 Revenge 框架"。一个 Frame 可有零到多个 lexUnit。

frameRelation (框架关系)

继承/使用/子框架

Frame 之间不是孤立的，有继承、视角、使用、子框架、前后顺序等关系，构成一张大网。

FE 的四种核心类型 (coreType)

Core

框架的核心角色，缺了它场景就不成立。比如"复仇"没有 Avenger 就不叫复仇。

Peripheral

外围角色：时间、地点、方式等修饰信息，可有可无。

Extra-Thematic

额外主题：描述性修饰、结果等，不直接参与核心逻辑。

Core-Unexpressed

核心但通常不显式说出来的角色，概念上必须存在但语言上常隐含。

FE 还有 requiresFE 和 excludesFE 两种约束：某 FE 出现时另一个"必须出现"或"不能出现"

FEcoreSet — 核心 FE 互斥组

同一组内的 FE 不会被同时表达，选一个就够。概念上它们"指向同一个东西"。
{ Injury 或 Injured_party }
{ Avenger 或 Punishment }
比如你可以说"为那次伤害复仇"(Injury) 或"为受害者复仇"(Injured_party)，但一般不同时说。

lexUnit (词汇单元) 详解

lexUnit = 词.词性

avenge.v revenge.n vengeful.a get even.v payback.n
lexUnit 的 name 格式必须是 "词.词性"（如 avenge.v）。
status 标注标注进度：Created → New → Insufficient_Attestations → Finished_Initial
definition 来自词典(FN/COD)的释义
sentenceCount total=语料总句数
annotated=已标注句数
semType 语义类型引用(ID+name)
lexeme ×1+ 构成词的词素单元
多词表达有多个lexeme

实战走一遍：Revenge (复仇) 框架

1

打开 Frame 根节点

frame 的 4 个属性：ID=347, name=Revenge, cDate=创建时间, cBy=创建者JKR
definition 描述："这个框架关于对所受伤害施加惩罚的回报。"

<frame ID="347" name="Revenge" cBy="JKR" cDate="06/10/2002 ...">
2

查看 FE（框架元素）— 13 个角色

每个 FE 有 name、abbrev、coreType、配色(bgColor/fgColor) 和定义。

Avenger 复仇者 Offender 犯错者 Punishment 惩罚 Injury 伤害 Injured_party 受害方 Degree Manner Instrument Place Time Purpose Duration Depictive Result
<FE name="Avenger" coreType="Core" bgColor="FF0000"> <definition>The Avenger exacts revenge...</definition> <semType name="Sentient" ID="5"/> </FE>
3

读 FEcoreSet — 哪些核心 FE 互斥

Revenge 有 2 组互斥核心 FE：

{Injury或Injured_party} "为那次伤害" vs "为受害者"
{Avenger或Punishment} "他复仇了" vs "以大胜报复"
<FEcoreSet> <memberFE name="Injury" ID="3018"/> <memberFE name="Injured_party" ID="3022"/> </FEcoreSet>
4

读 frameRelation — Revenge 继承自谁

Revenge 框架 继承自 Rewards_and_punishments 框架。其他关系类型为空。

<frameRelation type="Inherits from"> <relatedFrame ID="216">Rewards_and_punishments</relatedFrame> </frameRelation>

6

一句话走完全流程

输入句子："They took revenge for the deaths of two loyalist prisoners."

① 识别 Frame took revenge → 命中 Revenge 框架 (lexUnit: revenge.n)
② 标注 FE They = Avenger (Core)   for the deaths... = Injury (Core)
③ lexUnit revenge.n → sentenceCount: 34句已标注/364句总计
④ 关系定位 Revenge Inherits from Rewards_and_punishments → 可回溯上层框架

全图总结

  1. frame 是根，描述一个认知场景，有 ID/name/cDate/cBy
  2. FE 是场景中的角色，分 Core / Peripheral / Extra-Thematic / Core-Unexpressed 四类，有语义类型(semType)、互斥约束(requiresFE/excludesFE)、配色
  3. FEcoreSet 将可互换的核心 FE 组在一起，表达"二选一"语义
  4. lexUnit = 词.词性，是连接 Frame 与真实语言的桥梁；包含 definition、sentenceCount（标注进度）、lexeme（词素拆分）和 semType
  5. lexeme 是词素级别，支持多词表达（如 get even），用 order/headword/breakBefore 精确描述结构
  6. frameRelation 连接框架间 9 种关系（继承、视角、使用、子框架、前后序、起始、使役、另见），构成语义网络
  7. 核心流程：识别词 → 激活 lexUnit → 定位 Frame → 用 FE 标注句中角色 → 沿 frameRelation 扩展到相关框架
