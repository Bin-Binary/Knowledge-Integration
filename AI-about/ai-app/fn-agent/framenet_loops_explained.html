你从哪里进，能从哪里出

一个 FrameNet 词条文件（lu2.xml）的内部交通网：入口、接头暗号、出口一次讲清

🟢 入口（进去用哪个钥匙） 🔴 出口（拿得走什么成果）
01 · 先给一张总地图

六个栏目不是平铺，而是"手拉手"围着一个 ID 总线

每两个栏目之间靠"接头暗号"相连。暗号就是三类键：annoSet ID、FE name、corpID+docID。谁拿着键，谁就能从一段数据走到另一段。

🔗 annoSet IDvalences 的 pattern ↔ subCorpus 的 annotationSet。
例：784392
🔗 FE nameheader 图例 ↔ valences 单元 ↔ 句子里 label 的名字。
例：Cause / Effect
🔗 corpID + docID句子的出处 ↔ header 里的 corpus/document。
例：135 · 23511

① lexeme

词条身份：cause.v钥匙：词形/词性

② semType

语义类别标签钥匙：类型名

③ header

出处清单 + FE 图例钥匙：corpID/docID · FE name

④ valences

搭配公式（GF·PT）钥匙：annoSet ID · FE name

⑤ subCorpus

例句 + 逐词标注钥匙：annoSet ID · FE name

💡 另有一个对外接头暗号：句子里 label 的 feID（如 feID=20 表示 Effect）——它指向 FrameNet 数据库全局的 FE 表，把例句和"全库统一编号"接上。

02 · 三套接头暗号是怎么咬合的

用 lu2.xml 的"实拍 ID"演示每一套

暗号 ①：annoSet ID —— 公式 ↔ 实证 两处都写 784392
valences（第 174 行）　→　<pattern total="20"> valenceUnit GF=Ext PT=NP FE=Cause ＋ <annoSet ID="784392"/>
▲ 同一把钥匙 ▼
subCorpus（第 838 行）　→　<annotationSet ID="784392" status="MANUAL"> 在句子 651962 里

同一串数字把"Cause 常作主语"这句公式，和 "What caused you…" 这条真实句子钉成一个整体。valences 上挂的所有 annoSet，都能在 subCorpus 里翻到原句标注。

暗号 ②：FE name —— 句子 ↔ 图例 三处都写 Effect
sentences 的 label（第 841 行）　→　<label name="Effect" feID="20" start="12" end="14"/>
▲ ▼
valences 的 valenceUnit　→　<valenceUnit GF="Obj" PT="NP" FE="Effect"/>
▲ ▼
header 的图例（第 47 行）　→　<FE name="Effect" bgColor="FF0000" abbrev="Effect" type="Core-Unexpressed"/>

名字相同 = 说的是同一个语义角色。这一步让工具的"上色"成为可能：看到 label 的 name 是 Effect，就去 header 查 FE 的 bgColor=FF0000，于是红色就画上了。

暗号 ③：corpID + docID —— 例句 ↔ 出处 两处都写 135 · 23511
subCorpus 的 sentence（第 5267 行）　→　<sentence corpID="135" docID="23511" ID="4096661">
▲ ▼
header 的 corpus/document（第 8-9 行）　→　<corpus ID="135" name="NTI"> <document ID="23511" name="Iran_Nuclear"/>

每条句子都自带"护照号"，反查出它来自哪本书（NTI）的哪一章（Iran_Nuclear），跟 header 顶部的出处清单对得上。

03 · 四条标准线路

每条线都标好"入口"和"出口"

🟢→🔴 线路 一：从「公式」查到「原句证据」
入口：valences 的一个 pattern
进·钥匙拿到 pattern↔annoSet ID
784392
→
凭 ID 跳转去 subCorpus 找同 ID 的 annotationSet
第 838 行
→
出·成品原句 "What caused you to change your mind?" + 标注位置
🟢→🔴 线路 二：从「句子标注」上色/翻译成可读结果
入口：subCorpus 里一个 label
进·钥匙label 的 name=Effect、start/end 位置
→
按 name 去 header查 FE 的颜色/缩写
bgColor=FF0000
→
出·成品用颜色画出的句子、图例对照表（人一眼看懂）
🟢→🔴 线路 三：从「例句」追溯「出处」
入口：任何一条 sentence
进·钥匙sentence 的 corpID/docID
135 · 23511
→
按 ID 去 header定位 corpus/document 描述
NTI · Iran_Nuclear
→
出·成品可复现的文献出处、版权归属信息
🟢→🔴 线路 四：从「词条封面」进入整包知识
入口：lexeme / semType / lexUnit 根
进·钥匙词形+词性+frame
cause · V · Causation
→
根节点展开三个"大毛坯"自动绑好：header↔valences↔subCorpus
→
出·成品完整的词条档案：图例+公式+例句+类别标签全数导出
04 · 出口汇总（你能拿走的五样东西）

所有"出口"都是从这五扇门出去

1
可复现数据

每条例句可回到出处文档（corpID/docID），研究、引用、复现都说得清。

2
金色训练数据

subCorpus 里 MANUAL 标注的句子 = NLP 模型标准答案（句子切分到 FE/GF/PT）。

3
配价语法公式

valences 直接产出"X caused Y"这类可查的搭配规则，构成配价词典。

4
可视化渲染

FE name → header 颜色，把任意例句画成带色标注图（正是标注工具的工作）。

5
一致性校验

顺着三套暗号反查：ID 对不上、颜色不是 6 位、label 出界，机器当场报错。

05 · 一句话总结

入口是"钥匙"，出口是"成果"，中间是"三套暗号"

入口任何栏目 / 任何 IDlexeme 词、annoSet ID、FE name、corpID…
— 拿钥匙 →
ID 总线 + 三套暗号annoSet ID · FE name · corpID/docID
→ 搭桥 →
出口五扇门之一证据/数据/公式/渲染/校验

入口是任意一段数据，出口是你要的成果；
不管从哪边进，只要沿三套暗号走，就一定能到达另一边。文件自始至终是一个闭环——这就是它"环环相扣"的含义。
