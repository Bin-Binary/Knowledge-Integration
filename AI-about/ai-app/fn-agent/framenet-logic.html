五步执行流程

从一句自然语言到结构化语义表示

1
输入原始句子
系统接收到一句话，比如从文章、对话或搜索框中获取。
"The wolves devoured the carcass completely."
2
查找触发词 → 关联词汇单元 (LU)
在句子中找到"动作词"，去 lu/ 目录的 13,572 个词汇单元中匹配。触发词决定搜索哪个场景。
<!-- lu/ 目录中查找 "devour" --> <lexUnit name="devour.v" POS="V"> <definition>eat hungrily and quickly</definition> <lexeme name="devour"/> </lexUnit> <!-- 找到！devour.v 属于 Ingestion 场景 --> <frame>Ingestion</frame>
3
激活 Frame（场景） → 获取角色模板
拿到场景名后，去 frame/ 目录读取该场景的定义。拿到一张"角色空位表"——这个场景有哪些参与者位置需要填写。
<!-- frame/Ingestion.xml 中定义的角色 --> <FE coreType="Core" name="Ingestor"/> <!-- ★ 核心: 谁在吃 --> <FE coreType="Core" name="Ingestibles"/> <!-- ★ 核心: 吃什么 --> <FE coreType="Peripheral" name="Place"/> <!-- ○ 边缘: 地点 --> <FE coreType="Peripheral" name="Time"/> <!-- ○ 边缘: 时间 --> <FE coreType="Peripheral" name="Degree"/> <!-- ○ 边缘: 程度 --> <FE coreType="Peripheral" name="Manner"/> <!-- ○ 边缘: 方式 -->
4
标注 Fillers → 把句中成分填入角色
把句子的每个部分"对号入座"——哪个词扮演哪个角色。fulltext/ 中的 107 篇标注文章就是人工标注的范例，机器照此学习。
The wolves devoured the carcass completely
↓ 对号入座 ↓
角色 (FE)填入词 (Filler)类型
IngestorThe wolvesCore
Ingestiblesthe carcassCore
DegreecompletelyPeripheral
5
输出结构化语义 → 供下游使用
最终得到一组 (场景 + 角色映射) 的结构化数据，可送入问答系统、翻译引擎、情感分析等。
{ "frame": "Ingestion", "trigger": "devoured", "annotations": [ { "FE": "Ingestor", "text": "The wolves" }, { "FE": "Ingestibles", "text": "the carcass"}, { "FE": "Degree", "text": "completely" } ] }

程序视角：怎么用这套数据

以 NLTK 加载 FrameNet 为例的算法流程

1
加载 frameIndex.xml → 得到 1,221 个场景的 ID + 名称索引表
2
加载 luIndex.xml → 得到 13,572 个词汇单元的索引，建立 "词 → 场景ID" 的映射
3
对输入句子分词 → 逐词查 luIndex，找到匹配的词汇单元，确定候选场景
4
加载 frame/{场景名}.xml → 读取该场景的 FE 角色列表 + 语义类型约束
5
角色消解 → 将句中的名词短语等成分填入对应 FE，结合 fulltext/ 中的标注范例做训练/规则匹配
