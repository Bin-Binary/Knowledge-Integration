木叶隐村 · 情报解析班

frame-net / src

一支忍者小队，从成堆卷轴里提炼出「招式 · 谁 · 对谁」的秘籍
一句话：它读入一堆中文产品文档（云龙 CloudDragon 的 DevOps 说明），
像忍者小队执行「情报提炼」任务一样，自动筛出「动词 + 名词」的固定搭配，
最后写成一本 FrameNet 式语义框架秘籍。

✧六道工序✧

如同忍者修行，从「看破」到「搓成螺旋丸」，一步比一步精进。
P0 · 看破

解析

卡卡西 · 写轮眼
parser.py

切句、分词，看穿每句话里的「主谓宾」结构，标出每个词的语法角色。

➤
P1 · 收集

数搭配

自来也 · 情报
bigram.py

统计「哪个动词和哪个名词老是一起出现」，记下次数和出现文档数。

➤
P2 · 淘汰

过滤

佐助 · 千鸟
llr.py

用统计检验（LLR）一刀切，把偶然撞上的弱搭配全部淘汰，留下真高频的。

➤
P3 · 提纯

提纯

小樱 · 查克拉控制
entropy.py

看每个动词的宾语「专不专一」：专一→好种子；满天飞→轻动词（如「进行」）。

➤
P4 · 组合

扩三元

鸣人 · 影分身
trigram.py

在选中动词上前后多看一格，凑出「副-动-名」「介-名-动」三元组。

➤
P5 · 完成

定模板

鸣人 · 螺旋丸
trigram.py

用偏互信息（PMI）最后一筛，搓出完整的「框架骨架模板」。

✧成品长什么样✧

「部署流水线」
⇣
动词 部署 ＝ 一招「框架」(LU)
名词 流水线 ＝ 它的「槽位」(FE)
每道工序都同时产出 .json（给机器）和 .md（给人）两份卷轴。

✧十个文件，各司其职✧

每位忍者负责一件差事，队长在最后统筹全局。

pipeline.py 队长·统筹

把六道工序串成一条流水

P0→P1→P2→P3→P3.5→P4→P5 依次跑，最后写 run_report.json 汇总战报。

parser.py 卡卡西·写轮眼

P0 · 分词 + 浅层句法

规则版（jieba 词性 + 找主宾），另可切换 hanlp 深度解析。

bigram.py 自来也·情报

读语料 + P1 二元抽取

递归读 .txt、分句去噪，统计动词-名词共现。

llr.py 佐助·千鸟

P2 · LLR 显著性过滤

Dunning 对数似然比四格表，判「入选/淘汰」。

entropy.py 小樱·查克拉

P3 语义熵 + P3.5 义项检查

按宾语分布熵打标签，上下文聚类识别多义。

trigram.py 鸣人·螺旋丸

P4 三元抽取 + P5 过滤

组三元、算 PMI / 偏互信息，产出框架模板。

domain_dict.py 封印词表

领域词典 · 喂给分词器

让 jieba 认得「流水线 / pipeline_id / MR」等专名，别切错。

io_utils.py 卷轴书写官

落盘 · JSON + Markdown

统一写文件、渲染 Markdown 表格的工具。

cli.py 任务卷轴

入口 · 命令行开关

python -m 运行，可改语料路径、阈值等参数。

config.py 火影设定书

总参数 · 所有阈值

频率、LLR、熵、PMI 等全部可调，也可被环境变量覆盖。
