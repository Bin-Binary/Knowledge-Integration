明 · 辨 · 真 · 源

frame-net / src

一套「从语料里自动挖出『谁 · 做了什么 · 对谁』搭配」的加工流水线
一句话：它把一堆中文产品文档（云龙 CloudDragon 的 DevOps 说明），
像淘金一样，自动筛出「动词 + 名词」的高频固定搭配，
用来搭建一张 FrameNet 式语义框架网（谓语 + 它的槽位）。

六道工序

像一条山涧流水，语料从山顶流下，经过六站，最后沉淀出「框架模板」。
P0

解析

parser.py

把文档切句、分词、找出「主谓宾 / 动副 / 动介」的连线关系，给每个词标上语法角色。

→
P1

数搭配

bigram.py

统计「哪个动词和哪个名词老是一起出现」，记下次数和文档频率，形成原始共现表。

→
P2

过滤

llr.py

用统计检验（对数似然比 LLR）+ 频率门槛，淘汰偶然撞上的搭配，留下真「高频且显著」的。

→
P3

提纯

entropy.py

看每个动词的宾语「专不专一」：宾语很专一 → 好框架种子；宾语满天飞 → 轻动词（如「进行」）。

→
P4

扩三元

trigram.py

在选中的动词上，再往前、往后多看一格，组成「副词-动词-名词」「介词-名词-动词」三元组。

→
P5

定模板

trigram.py

用偏互信息（Partial PMI）再筛一遍，输出最终「框架骨架模板」（谓语 + 槽位）。

产出长什么样

「部署流水线」
⇣
动词 部署 ＝ 一个「框架」(LU)
名词 流水线 ＝ 它的「槽位」(FE)
每道工序都同时产出 .json（机器读）和 .md（人读）两份结果。

九个文件，各司其职

五行配色对应它们的「性子」：金=入口、木=生长、水=过滤、火=提纯、土=承载。
入

cli.py

入口 · 命令行开关

python -m 运行，可改语料路径、阈值等参数。

配

config.py

总参数 · 所有阈值

频率、LLR、熵、PMI 等全部可调，也可被环境变量覆盖。

析

parser.py

P0 · 分词 + 浅层句法

规则版（jieba 词性 + 找主宾），另可切 hanlp 深度解析。

取

bigram.py

读语料 + P1 二元抽取

递归读 .txt，分句去噪，统计动词-名词共现。

筛

llr.py

P2 · LLR 显著性过滤

Dunning 对数似然比四格表，判「入选/淘汰」。

熵

entropy.py

P3 语义熵 + P3.5 义项检查

按宾语分布熵给动词打标签，上下文聚类识别多义。

三

trigram.py

P4 三元抽取 + P5 过滤

组三元、算 PMI / 偏互信息，产出框架模板。

词

domain_dict.py

领域词典 · 喂给分词器

让 jieba 认得「流水线 / pipeline_id / MR」等专名，别切错。

出

io_utils.py

落盘 · JSON + Markdown

统一写文件、渲染 Markdown 表格的工具。

链

pipeline.py

总调度 · 把六站串起来

P0→P1→P2→P3→P3.5→P4→P5 依次跑，最后写一份 run_report.json 汇总。
