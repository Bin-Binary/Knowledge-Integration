# Bounded_entity
这是一个有界区域的抽象框架，主要用于FE继承

## 核心FE
- Bounded_area: 稳定的有界区域，常为名词的所指
- Constituent_parts: 构成有界区域的显著部分
- Relative_location: 有界区域的相对位置参照
- Name: 有界区域的名称
- Owner: 有界区域的所有者
- Formational_cause: 形成有界区域特征的原因

## 外围FE
- Type: 有界区域的类型
