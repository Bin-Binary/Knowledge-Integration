# Arranging
Agent将一个复杂的主题放入特定的配置中，该配置可以是一个正确的顺序，一个正确或合适的顺序，或者一个空间位置。他将元素排列成我们现在称之为周期表的图案。尽量按重要性排序

## 核心FE
- Agent: 使Theme处于特定Configuration 的人
- Theme: 由可配置部分组成的复杂实体
- Configuration: 排列后Theme或其组成成分所处的状态/关系

## 外围FE
- Purpose: Agent 改变 Theme 配置的目的
- Time: 排列发生的时间
- Manner: 排列行为的方式描述
- Means: AAgent 排列 Theme 的手段
- Location: Theme 被配置的位置

## 主题外功能FE
- Circumstances: Agent 排列 Theme 时的情境
- Instrument: Agent 改变 Theme 配置所用的工具
- Degree: 排列行为的程度
