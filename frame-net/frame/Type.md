# Type
这个框架与表示实体类型的名词有关。
子类型是指具有某些定义特性的更一般类别的成员的集合；或者，子类型仅指类型本身，即比更一般类别更具限制性的特征集。
集合中包含的项的属性可以由Item_Property指定。有时，子类型本身由某种类型属性描述。我不喜欢这种新奇的鱼。克莱奥不是我们这种人。他反对形式主义式的艺术分析。我想她指的是另一种类型

## 核心FE
- Category：子类型所属的更一般类别
- Subtype: 表示更一般类别的子类型

## 外围FE
- Type_property: 子类型本身的属性
- Item_property：类别成员的属性，帮助识别子类型所指的具体成员集合
