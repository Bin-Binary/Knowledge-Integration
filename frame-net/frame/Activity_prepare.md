# Activity_prepare
Agent为Activity做准备。部队正在为任务做准备。船只正准备离开码头

## 核心FE
- Agent: 准备活动的行为者
- Activity: Agent 所准备的活动


## 外围FE
- Place: 准备发生的地点
- Time: 准备发生的时间
- Manner: 准备的方式
- Means: 准备所使用的手段
- Duration: 准备持续的时间长度
- Degree: Agent投入准备的程度

## 主题外功能FE
- Purpose: Agent 准备的目的
- Depictive: 描述行为者状态的修饰语
- Beneficiary: 从准备事件中获益的参与者
- Iterations: 准备动作重复的次数
- Event_description: 将目标所描述的事态作为其他框架中的角色填充
