# Using
Agent为了达到某种目的而操纵一个Instrument

## 核心FE
- Agent: 使用工具以达成目的的行动者
- Purpose: 目的
- Instrument: Agent操纵以达成目的的实体

## 外围FE
- Place: Agent 使用 Instrument 的地点
- Time: Agent 使用 Instrument 的时间
- Means: Agent 使用 Instrument 的方式
- Manner: 行为的附加描述（如 quietly, deliberately）

## 主题外功能FE
- Role: Instrument 所关联的功能（如 as a pseudo jungle gym）
- Outcome: Agent 使用 Instrument 达成 Purpose 的成败
- Role: Instrument 包含使用行为的更大事件
- Containing_event: Agent 使用 Instrument 达成 Purpose 的成败
- Frequency: 事件发生的频率
- Period_of_iterations: 迭代解释的时间段修饰

- Circumstances: 独立于事件本身的世界状态描述
- Depictive: 参与者在行为期间的状态描述
- Explanation: 主句逻辑所依循的命题/原因
- Group: 使用事件发生的人群
- Degree: Instrument 或使用行为的可分级属性程度
- Duration: 使用行为持续的时间长度
