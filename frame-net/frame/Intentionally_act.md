# Intentionally_act
抽象框架，描述有意识行为者的行为。它主要是为了FE继承而存在的。我很容易地完成了契约

## 核心FE
- Agent: 执行有意识行为的行为者

## 外围FE
- Purpose: Agent的目的
- Time: 行为发生的时间
- Place: 行为发生的地点
- Manner: 行为发生的方式
- Means: 行为发生的手段

## 主题外功能FE
- Act: Agent 所执行的具体行为
- Domain: 行为领域，如 "political activity"
- Frequency: 行为的频率
- Period_of_iterations: 重复周期
- Result: 结果
- Explanation: 原因解释
- Event_description: 事件描述
- Apparent_conclusion: 表面推断
