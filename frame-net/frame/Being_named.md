# Being_named
这个框架涉及的实体通常被特定的名称所指代。她的名字叫萝拉

## 核心FE
- Name: 用于指称 Entity 的语言表达
- Entity: 被特定名称所指称的实体

## 外围FE
- Language: 名称所源自或致敬的人/事物所属语言
- Type: 名称的子类型（如 given name, surname）
- Context: 名称适用的区域或领域

## 主题外功能FE
- Descriptor: 对 Name 的某种描述
- Etymological_root: Name 的源语言或灵感来源
