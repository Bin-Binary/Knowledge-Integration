# Building
此框架描述装配或构造动作，其中代理将组件连接在一起以形成已描述的创建实体（Created_entity），因此是动词的对象。杰克用砖头盖了一座新房子。我们把飞机粘在一起。

## 核心FE
- Agent: 建造者
- Components: 构成所建实体的组件/材料
- Created_entity: 建造行为所产生的实体

## 外围FE
- Purpose: Agent 建造的目的
- Time: 建造发生的时间
- Place: 建造发生的地点
- Manner: 合并的方式
- Means: Agent 建造的手段
- Instrument: Agent 建造所用的工具

## 主题外功能FE
- Result: 建造行为的结果（如 together）
- Depictive: 描述建造参与者的状态
- Duration: 建造持续的时间
- Particular_iteration: 指示该事件嵌入重复系列中的某次实例
- Descriptor: Created_entity 的特征
- Period_of_iterations: 迭代事件的重复时段
