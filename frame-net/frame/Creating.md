# Creating
一个原因导致了一个创建实体的形成。

## 核心FE
- Created_entity: 被有意图地创建的实体
- Creator: 创建实体的行动者

## 外围FE
- Time: 创建发生的时间
- Manner: Creator 创建新实体的方式
- Purpose: Agent 引起改变的目的
- Means: Creator 创建新实体的手段
- Place: 创建发生的地点

## 主题外功能FE
- Components: 组合形成 Created_entity 的组成部分
- Depictive: 描述行为者/受影响者状态的描绘性短语
- Cause: 产生效果的事件或力量（Core-Unexpressed）
- Instrument: Creator 创建实体所用的工具
- Co-participant: 与 Creator 共同创建的次要行动者
- Purpose: Creator 创建新实体的目的
- Imposed_purpose: Creator 为 Created_entity 设定的用途
- Beneficiary: 从创建中受益的人
- Role: Created_entity 所担任/预期担任的角色
- Period_of_iterations: 迭代事件的重复时段
- Frequency: 单位时间内事件发生的次数
- Circumstances: 独立于事件的世界状态
- Recipient: 预期接收 Created_entity 的人

## FE关系
Excludes:
- Cause <-> Creator

## 框架关系
Inherits from(Transitive_action); 
Is Inherited by(Intentionally_create); 
Is Used by(Ingredients)
