# Instance
此框架涉及表示实体或事件类型的实例的透明名词。调查证实，管理层对团队运作的干预有所增加，在没有与团队协商的情况下作出管理决策的情况也有所增加

## 核心FE
- Instance: 某类型的一个具体事物或事件
- Type: 实例所属的类别，如 "specimens of this rare species"

## 外围FE
- Instance_prop: 实例的属性，如 "a clear example"
