# Activity_pause
代理在活动过程中暂停。1992年，政府冻结了定居点建设，以促进和谈。解除核冻结被认为是必要的，以产生所需的电力。

## 核心FE
- Agent: 在活动过程中暂停的主体
- Activity: Agent 暂停的活动

## 外围FE
- Place: Agent 暂停活动的时间
- Time: 准备发生的时间
- Manner: Agent 暂停活动的方式
- Means: Agent 暂停活动的手段
- Purpose: Agent 暂停活动的目的
- Completeness: Agent 暂停活动的程度
- Duration: 暂停的时长

## 主题外功能FE

- Depictive: 描述行为者状态的修饰语
- Legal_basis: Agent 暂停活动的法律依据
- Explanation: 主句逻辑上所跟随的命题
- Event_description: 描述整个目标从句的短语
