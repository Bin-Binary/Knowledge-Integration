# Filling
这些词是关于用某种东西、事物或物质填充容器和覆盖区域的词。区域或容器可以作为所有这些动词的直接宾语出现，并被指定为目标，因为它是主题的运动目标。与它的核论点地位相对应，它也在某些关键方面受到影响，不同于其他框架中的目标。Lionel Hutz在墙上涂上了油漆

## 核心FE
- Agent: 引发填充行为的行为者
- Theme: 改变位置/被放入的物品或物质
- Goal: 被填充的区域或容器
- Cause: 引起填满 Goal 的事件

## 外围FE
- Source: Theme 运动的起点（如 "from the whiskey bottle"）
- Path: 运动轨迹
- Degree: 填充的程度
- Manner: 填充的方式
- Means： 填充的手段
- Time: 填充发生的时间
- Place： 填充发生的地点
- Instrument：填充使用的工具

## 主题外功能FE
- Depictive: 描述 Agent 状态的短语
- Result： 填充后的结果状态
- Explanation — 填充的原因
- Purpose — 目的
- Subregion (Sub) — Goal 中被填充的局部区域（如 "on the forehead"）

## FE关系
Excludes:
- Agent <-> Cause
