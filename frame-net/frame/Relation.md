# Relation
实体_1和实体_2之间存在关系

## 核心FE
- Entity_1: 与 Entity_2 有关系的实体
- Entity_2: 与 Entity_1 有关系的实体

## 主题外功能FE
- Entities: Entity_1 和 Entity_2 的集合表达
- Relation_type: 关系的特征化描述（如 kinship）

## FE关系
**Excludes**
- Entity_1/Entity_2 <-> Entities

**Requires**
Entity_1 <-> Entity_2
