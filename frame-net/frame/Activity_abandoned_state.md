# Activity_abandoned_state
代理处于活动的未完成部分

## 核心FE
- Agent: 处于活动未完成状态的主体
- Activity: Agent 正在执行的过程

## 外围FE
- Place: 活动不再进行的地点
- Time: Agent 和活动保持未完成状态的时间
- Duration: 活动保持未完成的时长
