# Encoding
一个人（说话者）以某种特定的方式表达一种信息或广义上的精神内容。
内容可能是情绪化的，如在人类中，通过文字表达情感，如在仔细地表达想法，或在语言上，如你的问题作为评论。

## 核心FE
- Speaker: 编码/表达 Message 的人
- Message: 被表达的心理内容（情感/思想/语言）
- Manner: 表达行为的方式（如 carefully, as a question）
- Medium: 交流媒介（如所用语言、文本类型）

## 外围FE
- Addressee: 交流的接收者
- Means: Speaker 实现 Message 措辞的手段
