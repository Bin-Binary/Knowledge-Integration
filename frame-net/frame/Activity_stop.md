# Activity_stop
代理在未完成活动的情况下终止活动。在这场诉讼之后，该公司停止了生产这个曾经非常有利可图的玩具。1988年9月，橄榄球俱乐部终止了与阿盖尔的谈判

## 核心FE
- Agent: 停止活动的主体

## 外围FE
- Place: Agent 停止活动的地点
- Time: Agent 停止活动的时间
- Manner: Agent 停止活动的方式
- Duration: 活动停止的时长
- Degree: 停止的完整程度

## 主题外功能FE
- Purpose: Agent 停止活动的目的
- Depictive: 描述动作执行者或受事者状态的短语
- Result: 停止活动的结果
- Activity: Agent 停止的活动（†被归为 Extra-Thematic）
- Means: Agent 停止活动的手段
- Co-timed_event: 停止活动的最后同时事件
- Frequency: 事件发生的频率
- Containing_event: 包含该停止事件的外层事件
- Circumstances: 独立于事件及其参与者的世界状态
- Re-encoding: 将当前框架重新编码为更大概念化的一部分
- Explanation: Agent 停止活动的原因
- Event_description: 描述整个目标从句的短语
- Particular_iteration: 指示该事件嵌入在一系列类似事件中
