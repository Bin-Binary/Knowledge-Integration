# Activity_start
代理发起正在进行的活动的开始，他将持续参与其中。与此同时，城邦在希腊大陆南部的影响力开始增长。很自然，我开始哭着离开工作

## 核心FE
- Agent: 发起活动的行为者
- Activity: Agent 所开始的活动

## 外围FE
- Place: Agent 开始活动的地点
- Time: Agent 开始活动的时间
- Manner: Agent 开始活动的方式
- Means: Agent 开始活动的手段
- Purpose: Agent 开始活动的目的

## 主题外功能FE
- Depictive: 描述行为者状态的修饰语
- Co-timed_event: 活动开始时的首个同步事件，如 "The peace march started with a prayer."
- Circumstances: 独立于事件本身的背景状态
- Containing_event: Agent 开始活动时所处的大事件
- Event_description: 对目标从句整体的描述性修饰
- Explanation: 主句逻辑上所跟随的命题（原因）
- Particular_iteration: 指出该事件是重复系列中的第几次
- New_situation: 活动开始后紧接着的新状态
- Communicative_force: 话语的效力/权威性（如 officially, formally）
- Concessive: 让步修饰（虽有不预期的情况但事件仍发生）
