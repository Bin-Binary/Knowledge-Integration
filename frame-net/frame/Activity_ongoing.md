# Activity_ongoing
代理正在执行活动的部分，其中存在动态稳定性。曼尼没有注意到从窗前冲过来的人群，继续吃着他的午餐。继续实现梦想！

## 核心FE
- Agent: 从事持续活动的主体
- Activity: Agent 从事的持续活动
- Duration: 从持续状态开始到结束的时间长度

## 外围FE
- Place: 持续活动发生的地点
- Time: 持续活动发生的时间
- Manner: Agent 执行持续活动的方式
- Means: Agent 从事持续活动的手段

## 主题外功能FE
- Purpose: Agent 从事持续活动的目的
- Depictive: 描述行为者状态的修饰语
- Co-timed_event: 与持续活动同时发生的事件
- Explanation: 主句逻辑上所跟随的命题
- Iterations: 准备动作重复的次数
- Circumstances: 独立于事件及其参与者的世界状态
