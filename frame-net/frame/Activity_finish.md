# Activity_finish
代理完成了一个Activity，这个Activity就不能再逻辑上继续了。这个框架是Activity的一个子框架。詹森周日深夜完成了评卷工作。期末考试结束后，艾娃扔掉了她的笔记

## 核心FE
- Agent: 完成活动的主体
- Activity: Agent 已完成的活动

## 外围FE
- Place: Agent 完成活动的地点
- Time: 活动完成的时间
- Manner: Agent 完成活动的方式
- Means: Agent 完成活动的手段
- Degree: Agent 接近完成的程度
- Purpose: Agent 完成活动的目的

## 主题外功能FE
- Depictive: 描述行为者状态的修饰语
- Result: 完成活动的结果
- Co-timed_event: 完成活动的最后同时事件
- Explanation: 主句逻辑上所跟随的命题
- Circumstances: 独立于事件及其参与者的世界状态
- Containing_event: Agent 完成活动期间包含该活动的事件
