# Python内置组件概述
**Python的内置组件*是区别于标准库、第三方库、用户自定义组件的对象集合，无需import即可使用是其最直观的语法特征，
从而消除了手动引入的依赖管理开销。例如：

```python
"""语法特征"""

# 1. abs()是内置函数：无需import
print(abs(-10))  
# >>> print(abs(-10))
# 10

# 2. sqrt()是标准库函数：不写import就会直接报错（NameError）
print(sqrt(16))  
# >>> print(sqrt(16))
# Traceback (most recent call last):
#   File "<stdin>", line 1, in <module>
# NameError: name 'sqrt' is not defined

```

**Python的内置组件*为程序运行时提供开箱即用的基础能力集，由类型、常量、函数、异常、线程安全、性能六个维度构成
