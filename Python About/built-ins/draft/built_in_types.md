# Built-in Types

## 内置类型（Built-in Types）是什么
### 本体定义
内置类型是Python解释器内置的类，其中部分类（例如：数字、序列、映射、..）被视为语言"核心地位"。区别于用户自定义类和标准库类，Python语言核心定义了语法层面的字面量形式，并对它们的语义施加了一些限制（例如：真值测试、布尔运算、比较），但并未完全定义其语义。

### 功能
1. 语法简洁：位于内置命名空间无需import可直接书写；部分类型自带字面量，在编译期通过*LOAD_CONST*等专用字节码直接构造实例，而不需要经过 __new__ 和 __init__ 的完整堆栈调用
2. 能力分层：
    - 数据层——int、list、dict 等，承载程序运行时的值与结构
    - 协议层——iterator、context manager 等，定义行为契约，由鸭子类型从外部匹配（"如果它走起来像鸭子…"）
    - 元类型层——GenericAlias、UnionType 等，用于在类型注解中构造复合类型 
3. 开放扩展：虽然内置类型被施加了语义限制，但并未完全锁死其运行语义。
运算符的具体行为由双方方法的动态协商决定（如 a + b 依次尝试 a.__add__(b) → b.__radd__(a)），
与鸭子类型的外部协议匹配形成互补——前者解决"同类如何交互"，后者解决"什么算同类"
