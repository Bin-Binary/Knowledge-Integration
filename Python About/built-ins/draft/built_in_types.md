# Built-in Types

## 内置类型（Built-in Types）是什么
### 本体定义
内置类型是Python解释器内置的类，其中部分类（例如：数字、序列、映射、..）被视为语言"核心地位"。区别于用户自定义类和标准库类，Python语言核心定义了语法层面的字面量形式，并对它们的语义施加了一些限制（例如：真值测试、布尔运算、比较），但并未完全定义其语义。

### 功能
1.语法简洁：位于内置命名空间无需import可直接书写，自带字面量的类在AST编译期被优化、不需要构造函数可以得到实例
2.丰富的基础能力：内置类型包含数据类型、协议类型（例如：迭代器、上下文管理器）、类型构造类型（例如：泛型别名、联合类型）
3.开放扩展：虽然内置类型被施加了语义限制，但并未完全锁死其运行语义。具体行为完全交给各类型内部的方法去动态协商（例如：鸭子类型），从而为动态多态扩展留出了空间
