# 执行实体: 内存管理与执行模型

> Step 4 | N8→D9 | 突破维度: 时序

---

╔═══════════════════════════════════════════════════════════╗
║  【运行时】引用计数 / 分代GC / GIL / 编译执行              ║
║  编号: E012 | 来源: C120-C125                            ║
╚═══════════════════════════════════════════════════════════╝

【定义】 CPython内存: 引用计数(RC)为主+分代GC辅助; 执行: 源码→字节码→PVM执行; GIL: 全局互斥锁保证单线程字节码执行安全。

【冲突溯源】 N8→D9(分代GC+weakref: 弥补RC对循环引用的天然盲区, 双轨制回收), 突破维度: 时序

【设计内因】 D9工程目标: 在保留RC快速确定性释放的前提下, 补充分代GC处理循环引用(RC盲区), 用GIL保证RC操作的线程安全。
  通用困境:
  - (时序) RC循环引用盲区: l1→l2, l2→l1 → 两对象ob_refcnt均≥1永不归零
  - (时序) 多线程RC竞争: 两线程同时INCREF/DECREF → refcnt计数错误

  SC1(时序): [归属困境: 循环引用泄漏] 双向链表/树/图中节点互指→RC永远≥1→内存泄漏 [循环盲区约束] → 选择: 分代GC(三代gen0/1/2): 阈值触发→扫描对象图→可达分析→回收不可达环; weakref弱引用(不增refcnt)配合GC | 代价: GC timing不确定(stop-the-world暂停); __del__对象可能复活到gc.garbage

  SC2(时序): [归属困境: 多线程RC竞争] 2线程同时x=obj→INCREF竞速→refcnt错误→过早释放或泄漏 [线程安全约束] → 选择: GIL(PyThread_type_lock): 同时仅1线程执行字节码→RC操作天然原子性→无需per-object锁; I/O时释放GIL让其他线程跑 | 代价: CPU密集型多线程无效(始终单核); 真并行需multiprocessing

  SC3(时序): [归属困境: 对象深度复制] 拷贝复杂对象(含嵌套容器)→若浅拷贝则共享内部; 若深拷贝可能无限递归 [复制完整性约束] → 选择: copy.copy(浅—仅复制顶层容器, 元素INCREF引用); copy.deepcopy(深—递归复制, memodict防循环) | 代价: deepcopy可能RecursionError(超深嵌套)

【结构】"它长什么样？" {★}
- RC: ob_refcnt(Py_ssize_t)
- GC: 三代gen0/1/2, 阈值(700/10/10分配), PyGC_Head {gc_refs, gc_prev, gc_next}
- GIL: 一个pthread_mutex(PyThread_type_lock)
- 编译/执行: .pyc文件存magic nnumber+时间戳+字节码, ceval.c主循环

【时序】"它按什么顺序动？" {★★★}
- RC: INCREF→refcnt++; DECREF→归零→tp_dealloc→调用free
- GC: gen0达阈值700→回收gen0可达分析→存活晋升gen1→gen1达10→回收gen0+1→存活晋升gen2→gen2达10→full GC
- GIL: 线程获GIL→执行~100字节码→释放→下线程获→I/O时主动释放
- 编译: .py→tokenize→parse(AST)→符号表→字节码(PyCodeObject)→peephole优化→.pyc缓存
- 深拷贝: 新memo字典→递归→不可变对象回引用→可变对象创建新容器+递归填充

【实体】"它的最小数据单元？" {★}
- ob_refcnt: ssize_t
- GC头部: PyGC_Head (3个指针)
- PyCodeObject: co_code(字节码bytes), co_consts, co_stacksize

【边界】"它在哪里交出控制权？" {★}
- GC: 非确定触发, stop-the-world暂停
- GIL: CPU密集无加速, I/O密集有效(I/O时释放)
- __del__析构: 不确定时机(GC顺序), 可能永不调用
- .pyc跨版本: magic number不兼容不同Python版本

【内部关联】
- INCREF --[触发(引用→计数)]--> ob_refcnt++
- DECREF --[触发(归零→析构)]--> ob_refcnt==0 → tp_dealloc
- GC.collect() --[触发(循环扫描→回收)]--> 对象图可达分析
- GIL --[触发(锁→串行)]--> 单线程字节码执行
- copy.deepcopy --[触发(递归→独立副本)]--> memo dict防循环复制

【示例】
```python
import gc, weakref, copy
gc.collect()  # 手动触发GC

# 浅vs深拷贝
a = [[1,2], [3,4]]
b = copy.copy(a)
c = copy.deepcopy(a)
a[0][0] = 99
print(b[0])  # [99,2] (共享内部)
print(c[0])  # [1,2]  (独立)

# weakref (不增refcnt)
class Node: pass
n = Node()
r = weakref.ref(n)
print(r())    # <Node object>
del n
print(r())    # None

# 字节码速览
import dis
def add(a,b): return a+b
dis.dis(add)
```
