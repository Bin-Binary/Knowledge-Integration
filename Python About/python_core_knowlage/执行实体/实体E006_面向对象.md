# 执行实体: 面向对象

> Step 4 | N0→D1 + N1→D2 | 突破维度: 结构

---

╔═══════════════════════════════════════════════════════════╗
║  【类型系统】class / 继承MRO / 描述符 / property           ║
║  编号: E006 | 来源: C070-C079                            ║
╚═══════════════════════════════════════════════════════════╝

【定义】 class语句创建PyTypeObject(type实例), 执行类体收集定义; 继承通过C3线性化确定MRO; 描述符协议(__get__/__set__/__delete__)统一属性访问行为。

【冲突溯源】 N0→D1(类也是PyTypeObject: 统一对象模型的自然延伸) + N1→D2(异常继承层次: 用类的继承组织异常分类), 突破维度: 结构

【设计内因】 D1工程目标: 类也是类型对象, 类定义是可执行代码, OOP机制完全由运行时构建而非编译器硬编码。
  通用困境:
  - (结构) 多继承菱形冲突: D→B(A),D→C(A)形成菱形, A的方法被B和C各重载一次→哪个优先?
  - (实体) 实例属性dict的内存浪费: 每个实例都有__dict__存属性, 大量小实例时dict比数据大

  SC1(结构): [归属困境: 菱形冲突] C3线性化: 输入多重继承序列, 生成满足单调性(子类<p父类)和一致性(父类间局部顺序不变)的线性化 [优先确定性约束] → 选择: C3算法生成__mro__ tuple, 属性查找沿__mro__逐类搜索[sound & complete] | 代价: C3失败时(TypeError)拒建类; 需手动调整父类顺序

  SC2(实体): [归属困境: 实例dict的内存膨胀] 每个实例有PyDictObject存属性, Point(3,4)的__dict__比(x,y)数据大 [内存效率约束] → 选择: __slots__: 类tp_members C数组存属性指针替代实例__dict__, 节省16+bytes/实例 [紧凑存储] | 代价: 无__dict__→不能动态加属性; 继承链需重复声明

  SC3(时序): [归属困境: 属性访问优先级] 数据描述符(property)和实例dict冲突时谁先? [查找确定约束] → 选择: 数据描述符 > instance.__dict__ > 非数据描述符 > class.__dict__, 保证@property优先级 | 代价: 设置inst.attr却发现被property拦截→混淆

  SC4(时序): [归属困境: 方法自动绑定] instance.method需自动传self, 不能每次手动 [绑定机制约束] → 选择: function是描述符(有__get__), instance.method → func.__get__(instance) → bound method | 代价: 绑定方法对象额外分配(通常可忽略)

【结构】"它长什么样？" {★★★}
- 类 = PyTypeObject: {tp_name, tp_bases(tuple), tp_dict(dict), tp_call}
- 实例: {ob_refcnt, ob_type→类, __dict__ (无slots时)}
- MRO: __mro__ = (C3结果tuple)
- 描述符: property/classmethod/staticmethod皆实现描述符协议

【时序】"它按什么顺序动？" {★★}
- 属性查找链: 数据描述符>instance.__dict__>非数据描述符>class.__dict__>MRO上溯
- 实例创建: cls.__call__ → __new__ → __init__
- MRO查找: __mro__[0]→__mro__[1]→…→object

【实体】"它的最小数据单元？" {★★}
- class.__dict__: 方法/类变量/描述符
- instance.__dict__: 实例属性(无slots)
- __slots__: C数组(PyMemberDef紧凑存储)
- __mro__: tuple of class objects

【边界】"它在哪里交出控制权？" {★}
- 元类__call__: 所有实例创建的统一入口
- super(): 依赖编译器魔法(__class__隐式注入)
- 属性查找失败: AttributeError

【内部关联】
- instance.ob_type --[配对(实例→类型)]--> PyTypeObject
- class --[使用(类型→元类型)]--> metaclass(默认type)
- method --[配对(方法→实例绑定)]--> self (通过描述符__get__)
- super() --[触发(委托→MRO)]--> __mro__[pos+1:] 下一个类
- property --[使用(描述符→函数)]--> fget / fset / fdel

【示例】
```python
class Point:
    __slots__ = ('x', 'y')
    def __init__(self, x, y): self.x, self.y = x, y
p = Point(3, 4)
# p.z = 5  # AttributeError (无__slots__)

class A: pass
class B(A): pass
class C(A): pass
class D(B, C): pass
print(D.__mro__)  # D,B,C,A,object (C3线性化)
```
