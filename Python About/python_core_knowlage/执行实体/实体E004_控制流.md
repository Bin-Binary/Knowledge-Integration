# 执行实体: 控制流

> Step 4 | N5→D6 | 突破维度: 时序

---

╔═══════════════════════════════════════════════════════════╗
║  【控制结构】if / for / while / break / continue / match   ║
║  编号: E004 | 来源: C040-C044                            ║
╚═══════════════════════════════════════════════════════════╝

【定义】 if/elif/else: 基于布尔条件的分支; for: 遍历可迭代对象的确定性循环(基于迭代器); while: 条件驱动非确定性循环; break/continue/else: 循环控制子句; match/case: 3.10+结构化模式匹配。

【冲突溯源】 N5→D6(迭代器协议统一遍历: for循环基于迭代器而非索引, 消除越界错误), 突破维度: 时序

【设计内因】 D6工程目标: 用统一for-in语法遍历一切可迭代对象, 消除C风格索引循环的越界/负索引/边界错误。
  通用困境:
  - (时序) 遍历+索引 vs 遍历+迭代器: C for(i=0;i<n;i++)暴露索引, 越界和fencepost错误频发
  - (时序) 循环正常结束 vs break中断检测: 需区分二者但无直接语言支持

  SC1(时序): [归属困境: 索引暴露安全问题] for(i=0;i<n;i++)中i可控但越界→未定义行为 [正确性约束] → 选择: for x in obj: 仅通过iter()+next()消费, 内部迭代器自动跟踪位置(无索引暴露); 需索引时用enumerate | 代价: 无法在迭代中随机访问; 无法在遍历中获取索引需额外enumerate

  SC2(时序): [归属困境: 正常结束检测] 需区分"循环自然完成"vs"中间被break", 但break后隐式跳转破坏结构化 [控制流分离约束] → 选择: for/while支持else子句(不被break时执行, 包括0次迭代) | 代价: else命名歧义(≠if else), 初学者常见误解

  SC3(时序): [归属困境: 多分支结构解构] if-elif链在复杂数据结构场景下冗长且易错 [声明式匹配约束] → 选择: match/case(Python 3.10+)编译为字节码决策树, 支持字面量/解构/类/守卫 | 代价: match需要类型.__match_args__支持类匹配

【结构】"它长什么样？" {★★}
- if/elif/else: 条件链, 仅执行首个匹配分支
- for/while: break跳→循环下1条, continue跳→下次迭代, else 正常完成后执行
- match/case: 模式(字面量/序列/映射/类/或) + 可选if守卫

【时序】"它按什么顺序动？" {★★★}
- for x in obj: iter(obj)→next()→绑定变量→body→StopIteration→else
- while cond: 测→True→body→回测→…→False→else
- match subject: 按case顺序测试首个成功分支执行后退出(无穿透)
- 短路: and/or在确定时停止求值

【实体】"它的最小数据单元？" {★}
- for隐式持有迭代器对象(栈上临时引用)
- range对象: {start, stop, step} 惰性计算

【边界】"它在哪里交出控制权？" {★}
- next()触发迭代器.__next__用户代码
- 遍历时修改list: RuntimeError
- while True无break: 永不退出

【内部关联】
- for x in obj --[触发(遍历→迭代消费)]--> obj.__iter__ → iterator.__next__
- break --[配对(中断→跳出)]--> 循环体后第一条语句
- continue --[配对(跳过→回测)]--> 循环条件/迭代器next
- else --[配对(循环→正常完成)]--> 未被break中断
- match --[触发(解构→类匹配)]--> cls.__match_args__

【示例】
```python
for i in range(3):
    if i == 1: continue
    print(i)       # 0 2
else:
    print("done")  # done

match [1, 2]:
    case [a, b] if a < b: print(f"{a}<{b}")  # 1<2
    case _: print("other")
```
