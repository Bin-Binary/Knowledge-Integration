# 执行实体: 装饰器与注解

> Step 4 | N7→D8(装饰器) + N4→D5(注解) | 突破维度: 结构

---

【定义】 装饰器: 接受callable返回新callable的高阶函数; @语法糖: f=dec(f)编译时包装; 注解(__annotations__): 函数/类的类型元数据字典, 无运行时强制力; f-string: 内嵌表达式的字符串格式化。

【冲突溯源】 N7→D8(装饰器: 不修改原代码复用横切逻辑) + N4→D5(注解: 显式化接口契约—函数签名类型约束文档化), 突破维度: 结构

【设计内因】 D8工程目标: 用高阶函数包装复用横切逻辑(日志/计时/缓存/权限)而不修改原函数源码。
  通用困境:
  - (结构) 横切逻辑侵入性: log/timeit等重复代码散布每个函数内部, 反DRY
  - (时序) 装饰器执行vs调用时机: @dec在定义时执行(import瞬间), 若重构逻辑则延迟加载
  - (结构) 接口契约缺失: 动态类型无签名类型约束→纯依赖文档易不同步

  SC1(结构): [归属困境: 横切逻辑侵入] 每个func开头重复写log/timeit→散漫难改 [代码复用约束] → 选择: 装饰器=高阶函数: @trace ⇔ func = trace(func), wrapper内写横切逻辑 [非侵入包装] | 代价: 堆叠增加调用深度; functools.wraps保持__name__/__doc__/__wrapped__

  SC2(时序): [归属困境: 时机陷阱] @dec在定义时执行(import瞬间)vs每次调用时执行—若装饰器有重逻辑→import慢 [时机拆分约束] → 选择: 装饰器工厂模式 @d(args): d(args)在定义时执行(轻量预置), inner wrapper在每次调用时执行(核心逻辑) [两阶段分离] | 代价: 两层嵌套增加理解成本

  SC3(结构): [归属困境: 接口契约] 纯文档描述参数类型→人工不同步→误用 [契约显式约束] → 选择: __annotations__ dict存类型提示+typing模块(PEP 484—List[int]/Optional[X]/Union[])—由mypy/pyright检查 | 代价: 注解无运行时强制力(需外部工具); from __future__ import annotations 字符串化延迟求值

【结构】"它长什么样？" {★★★}
- 装饰器: callable→callable
- @d: 编译时 → 等价 f = d(f)
- @d(args): → 等价 f = d(args)(f) (装饰器工厂)
- __annotations__: dict {param: type, "return": type}
- f-string: 编译为FORMAT_VALUE字节码→每个expr求值→调用__format__

【时序】"它按什么顺序动？" {★★}
- @d1@d2@d3 → f = d1(d2(d3(f))) # 从内向外应用(下向上)
- 装饰器在定义时执行(非调用时)
- f-string: 每个{}->运行时求值→__format__→拼接

【实体】"它的最小数据单元？" {★}
- __annotations__: dict (每个函数/类由编译器生成)
- functools.wraps: 复制__name__/__doc__/__module__到wrapper

【边界】"它在哪里交出控制权？" {★}
- 装饰器class: 用于装饰普通函数可能破坏__call__语义
- annotations: from __future__ import annotations字符串化延迟求值
- f-string仅限字面量(不可从变量动态生成格式)

【内部关联】
- @decorator --[触发(包装→替换)]--> func = decorator(func)
- @d(args) --[触发(工厂→装饰器)]--> real_decorator = d(args)
- __annotations__ --[使用(元数据→类型提示)]--> typing.get_type_hints()
- f-string --[触发(表达式→求值)]--> 当前作用域变量

【示例】
```python
import functools

def timer(func):
    @functools.wraps(func)
    def wrapper(*a, **kw):
        import time; t0 = time.time()
        r = func(*a, **kw)
        print(f"{func.__name__}: {time.time()-t0:.3f}s")
        return r
    return wrapper

@timer
def slow(): sum(range(10**6))
slow()  # slow: 0.015s

# 装饰器工厂
def repeat(n):
    def dec(func):
        @functools.wraps(func)
        def w(*a,**kw):
            for _ in range(n): func(*a,**kw)
        return w
    return dec

@repeat(3)
def hi(): print("hi")  # 打印3次

# 注解
def greet(name: str) -> str:
    return f"Hello {name}"
print(greet.__annotations__)  # {'name': str, 'return': str}
```
