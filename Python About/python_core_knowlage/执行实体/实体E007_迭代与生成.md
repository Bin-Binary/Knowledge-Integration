# 执行实体: 迭代与生成

> Step 4 | N5→D6 | 突破维度: 时序

---

╔═══════════════════════════════════════════════════════════╗
║  【迭代协议】iterator / generator / yield / 推导式         ║
║  编号: E007 | 来源: C060-C064                            ║
╚═══════════════════════════════════════════════════════════╝

【定义】 可迭代对象(iterable)实现__iter__返回迭代器; 迭代器(iterator)实现__next__消费元素; 生成器(generator)是含yield函数的惰性迭代器; 推导式是声明式构建序列的语法糖。

【冲突溯源】 N5→D6(迭代器协议统一遍历+生成器惰性产出一—消除索引循环边界错误+大序列内存峰值), 突破维度: 时序

【设计内因】 D6工程目标: 用迭代器协议和生成器实现内存安全的惰性遍历, 统一任意数据源的消费语义。
  通用困境:
  - (时序) 迭代-索引解耦: 索引遍历依赖随机访问, 链表/文件/网络流不适用
  - (时序) 大序列内存峰值: 预先生成全部数据(如range(1e9)→list)内存爆满

  SC1(时序): [归属困境: 迭代-索引解耦] C/Java for(索引)假设O(1)随机访问→对链表/流不适用 [通用遍历约束] → 选择: for x in obj: 仅调用iter()+next()→StopIteration; 任意实现__iter__/__next__的对象皆可for-in; range对象惰性产整数 | 代价: 迭代器一次性消费—需新iter()重置; 无法切/索引

  SC2(时序): [归属困境: 大序列内存峰值] 若预先物化全部元素(如list(range(1e9)))→GB级内存 [OOM安全约束] → 选择: 生成器(yield)逐项惰性产出→恒定内存; map/filter/zip返回惰性迭代器; 比较: 推导式立即物化 vs 生成器表达式惰性 | 代价: 惰性迭代器不可切; 需list()显式物化

  SC3(时序): [归属困境: 生成器单向vs双向] 迭代器仅单向消费(next), 无法inject数据→协程模式受限 [双向通信约束] → 选择: gen.send(v)→inject值到yield表达式; gen.throw(e)→注入异常; gen.close()→清理; yield from→委派子生成器(双向转发send/throw/close) | 代价: 必须先next()启动; send(None)=next()

【结构】"它长什么样？" {★★}
- 迭代器协议: __iter__→self, __next__→下一元素/StopIteration
- PyGenObject: {gi_frame(暂停的栈帧存堆), gi_code, gi_running, gi_yieldfrom}
- 推导式: 编译为for-if循环+.append(列表)/.add(集合)/__setitem__(字典)/yield(生成器表达式)

【时序】"它按什么顺序动？" {★★★}
- for x in it: iter(it)→next()→bind→body→loop→StopIteration
- gen = g(): 创建PyGenObject, gi_frame未执行
- next(gen): 启动到首个yield→产出→暂停→gi_frame存活
- gen.send(v): 恢复→yield收到v→继续→下个yield→暂停
- yield from sub: gen↔sub双向通道(send/throw/close传递给sub)

【实体】"它的最小数据单元？" {★★}
- gi_frame: f_lasti(指令指针), f_locals(局部变量), f_valuestack(值栈)
- range: {start, stop, step} 惰性计算
- list_iterator: {it_seq(PyListObject*), it_index(当前位置)}

【边界】"它在哪里交出控制权？" {★}
- yield: 控制权返回调用者(stateful暂停)
- 生成器重入: gi_running=True时调next→ValueError
- 遍历时修改list: ob_size检测→RuntimeError

【内部关联】
- iterable.__iter__ --[使用(工厂→产品)]--> iterator
- iterator.__next__ --[触发(消费→StopIteration)]--> 循环终止
- gen.send(v) --[触发(注入→yield)]--> yield表达式返回值
- yield from --[配对(委派→子生成器)]--> 子生成器双向通信
- 推导式 --[触发(编译→循环)]--> for-in + append/add/__setitem__

【示例】
```python
def fib():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b
g = fib()
print([next(g) for _ in range(5)])  # [0,1,1,2,3]

# 生成器表达式 (惰性)
gen = (x**2 for x in range(10**9))  # 不分配GB内存
print(next(gen))  # 0

# 字典推导 (立即物化)
print({w: len(w) for w in "a bb ccc".split()})
# {'a':1, 'bb':2, 'ccc':3}
```
