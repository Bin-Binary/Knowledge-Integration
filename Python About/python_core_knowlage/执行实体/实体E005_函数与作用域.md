【定义】 def创建PyFunctionObject(代码对象+闭包环境)+运行时调用压栈帧执行字节码; 名字解析遵循LEGB(Local→Enclosing→Global→Built-in); 函数是一等公民。

【冲突溯源】 N0→D1(函数是一等对象: 可赋值/传参/返回, 与int无特权差异) + N2→D3(快速调用: C扩展tp_slots快通道), 突破维度: 结构

【设计内因】 D1+D3工程目标: 函数是"一等公民"——可传参/返回/赋值, 调用语义统一于tp_call, 闭包实现外层变量堆存。
  通用困境:
  - (结构) 嵌套函数环境捕获: 内层函数需访问外层变量→外层返回后局部栈帧销毁→变量失效
  - (时序) 默认参数求值时机: 每次调用求值代价高 vs 定义时求值可变默认共享

  SC1(结构): [归属困境: 嵌套环境捕获] def嵌套时内层访问外层x→外层返回后x在C栈上消失 [生命周期越界约束] → 选择: 闭包(Cell对象): 编译器扫描自由变量→生成PyCellObject→func_closure持有→外层变量脱离C栈进入堆(通过Cell可达) | 代价: Cell间接访问多一次指针解引用; 循环中闭包共享同一Cell(经典陷阱)

  SC2(时序): [归属困境: 默认参数求值时机] 可变默认参数(def f(x=[]))若每次调用求值→内存开销; 若定义时一次性求值→重复调用共享同一可变对象 [语义选择] → 选择: 默认值在def执行时求值一次(函数定义时刻, 非每次调用) | 代价: f(x=[])多次调用共享同一列表(经典陷阱); 推荐用None哨兵

  SC3(时序): [归属困境: 可变参数收集] 函数需接收不定长参数→解析+分类 [灵活性约束] → 选择: *args(多余位置→tuple), **kwargs(多余关键字→dict), keyword-only参数(在*之后), positional-only(在/之前) | 代价: **kwargs每调用构建新dict

【结构】"它长什么样？" {★★★}
- PyFunctionObject: {func_code, func_globals, func_defaults(tuple), func_closure(tuple of Cell), func_qualname}
- 名字空间: PyDictObject
- Cell: PyCellObject {ob_ref(PyObject*)} 自由变量存储

【时序】"它按什么顺序动？" {★★}
- 调用序列: 创建栈帧→参数绑定(位置→关键字→*args→**kwargs→默认值补→keyword-only)→字节码执行→return/异常→清理帧
- 名字查找: Local→Enclosing→Global→Built-in: 搜→无则NameError
- lambda: 与def同机制(限制单表达式, 无语句)

【实体】"它的最小数据单元？" {★}
- func_code: PyCodeObject {co_code, co_varnames, co_consts…}
- func_closure: tuple of PyCellObject*

【边界】"它在哪里交出控制权？" {★}
- 调用栈最大深度: sys.getrecursionlimit()(默认1000)
- C扩展调用: 穿越Python/C边界, GIL释放点
- exec/eval: 执行任意代码→安全风险

【内部关联】
- func_code --[配对(函数→字节码)]--> PyCodeObject
- func() --[触发(调用→帧创建)]--> PyFrameObject(f_locals+f_globals)
- Cell.ob_ref --[使用(闭包→自由变量)]--> PyObject
- global x --[触发(重定向→模块级)]--> func_globals["x"]
- nonlocal x --[触发(重定向→外层)]--> 外层func_closure中的Cell

【示例】
```python
# 可变默认参数陷阱
def f(lst=[]): lst.append(1); return lst
print(f())  # [1]; print(f())  # [1,1]!

# 闭包
def make_adder(n):
    def adder(x): return x + n
    return adder
add5 = make_adder(5)
print(add5(3))  # 8

# 参数系统
def g(a, b=0, *args, c, **kwargs): pass
g(1, 2, 3, 4, c=5, d=6)
# a=1, b=2, args=(3,4), c=5(keyword-only), kwargs={'d':6}

# 循环闭包陷阱
funcs = []
for i in range(3):
    funcs.append(lambda: print(i))  # 所有lambda共享同一Cell!
funcs[0]()  # 2 (非0)
# 修复: lambda i=i: print(i)
```
