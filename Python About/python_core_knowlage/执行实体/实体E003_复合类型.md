# 执行实体: 复合数据结构

> Step 4 | N0→D1 + N3→D4 | 突破维度: 实体

---

╔═══════════════════════════════════════════════════════════╗
║  【数据类型】list / tuple / dict / set / frozenset         ║
║  编号: E003 | 来源: C030-C036                            ║
╚═══════════════════════════════════════════════════════════╝

【定义】 list: 可变动态指针数组; tuple: 不可变定长数组(可哈希); dict: 有序(3.7+)开放寻址哈希表; set: 无序可变哈希集合; frozenset: 不可变集合(可哈希)。

【冲突溯源】 N0→D1(一切皆对象: 容器也是PyObject) + N3→D4(内存优化: 紧凑dict PEP 412 / tuple单例 / __slots__ 同类), 突破维度: 实体

【设计内因】 D1+D4工程目标: 提供O(1)级查找性能的内置复合类型, 同时通过紧凑内存布局控制空间开销。
  通用困境:
  - (实体) 哈希表负载率: 负载过高冲突频繁→O(1)退化; 负载过低空间浪费
  - (时序) 动态序列扩容: 每次append都realloc退化为O(n)

  SC1(实体): [归属困境: 哈希表负载率] 开放寻址中负载>2/3时冲突率指数增长→查找退化 [性能约束] → 选择: 紧凑dict(PEP 412): dk_indices(1字节稀疏索引)+dk_entries(紧凑键值数组), 负载达2/3扩容×2 | 代价: 删除留DKIX_DUMMY墓碑→空洞垃圾; 高频增删后需gc.collect

  SC2(时序): [归属困境: 序列动态扩容] list.append→若无预留则realloc+memcpy≈O(n) [摊销性能约束] → 选择: 扩容策略allocated≈ob_size+(ob_size>>3)+(ob_size<9?3:6), 摊销O(1) | 代价: allocated空闲空间浪费内存

  SC3(实体): [归属困境: 不可变键的哈希性] dict/set的key必须可哈希, 但常见可变类型(set/list)不可哈希 [哈希安全约束] → 选择: tuple(不可变序列, 实现__hash__)+frozenset(不可变set), 空tuple单例 | 代价: 需手动构造冻结版本; tuple内若含可变元素仍无法哈希

【结构】"它长什么样？" {★★}
- list: PyListObject {ob_item(PyObject**), ob_size, allocated}
- tuple: PyTupleObject {ob_item[1](柔性数组)}, ()全局单例
- dict: PyDictObject {ma_keys(dk_indices+dk_entries), ma_values}
- set: PySetObject {table(setentry*), fill, used, mask}

【时序】"它按什么顺序动？" {★★}
- list[i]: O(1)指针偏移; append摊销O(1); insert(i) O(n)
- dict[key]: hash→索引→先is后==O(1)均摊; 遍历按dk_entries插入顺序
- set运算(&|^-): 遍历较小集合O(n)

【实体】"它的最小数据单元？" {★★★}
- list.ob_item: PyObject** (指针数组, 不持有对象本体)
- dict.dk_entries: PyDictKeyEntry {me_hash(预存), me_key, me_value}
- dict.dk_indices: char[dk_size] (1字节稀疏索引→entries位置)
- set.table: setentry {hash, key} (无value, 共享dict核心哈希逻辑)

【边界】"它在哪里交出控制权？" {★}
- dict扩容: 全表重哈希O(n)→瞬间暂停
- list.sort: 调用元素__lt__→用户定义不可预知
- 遍历时修改: list检测ob_size变化→RuntimeError

【内部关联】
- dict[d[key]] --[触发(查找→哈希)]--> key.__hash__ + key.__eq__
- list.ob_item[i] --[使用(容器→元素引用)]--> PyObject* (INCREF/DECREF)
- frozenset --[配对(不可变→可哈希)]--> dict.set的key约束
- tuple() --[使用(单例→所有空元组)]--> 全局PyTupleObject单例
- set.table --[使用(哈希表→与dict共享核心)]--> setobject.c

【示例】
```python
d = {"a": 1}; d["b"] = 2
print(d)                 # 保持插入顺序

lst = [1, 2]; lst.append(3)
print(lst)               # [1, 2, 3]

fs = frozenset([1, 2, 3])
d2 = {fs: "key"}         # frozenset可作为dict key
t = ()                   # 指向全局空tuple单例
```
