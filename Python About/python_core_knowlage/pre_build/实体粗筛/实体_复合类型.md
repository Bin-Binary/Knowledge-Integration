╔═══════════════════════════════════════════════════════════╗
║  【数据类型】列表 list                                     ║
║  编号: E007 | 来源: 提取清单C030                         ║
╚═══════════════════════════════════════════════════════════╝

【定义】 列表是可变、有序、可重复的元素序列，底层为动态数组(PyObject* 指针数组)，支持常数时间索引和摊销O(1)追加。

【结构】"它长什么样？"
- PyListObject: {ob_refcnt, ob_type, ob_size, ob_item(PyObject** 指针数组), allocated(分配容量)}
- 当 allocated > ob_size 时预留空间，避免每次append重分配
- 增缩策略: 扩容时 allocated ≈ ob_size + (ob_size >> 3) + (ob_size < 9 ? 3 : 6)
- 元素是对象引用(指针), 不是对象本身

【时序】"它按什么顺序动？"
- 索引访问(item[i]): 指针数组偏移 O(1)
- 追加(item.append(x)): INCREF(x) → 放入ob_item[ob_size] → ob_size++ → 若满则realloc扩容(摊销O(1))
- 插入(item.insert(i, x)): 移位[i:]元素 O(n)
- 删除(item.pop()): 返回ob_item[ob_size-1] → ob_size-- → DECREF(可能O(n)若删除内部元素)
- 排序(item.sort()): Timsort O(n log n), 稳定排序
- 遍历: for x in lst → 调用__iter__ → 逐索引返回元素

【实体】"它的最小数据单元？"
- ob_item: PyObject* 数组
- 元素存储的是对象指针(引用), 列表不拥有对象本体

【边界】"它在哪里交出控制权？"
- 扩容: 内存分配(realloc)是系统调用, 可能失败(OOM)
- 元素比较: 排序时调用__lt__, 用户自定义可能开销不可预知
- 元素析构: 删除元素时DECREF, 若refcnt→0触发对象销毁链式反应

【内部关联】
- list.ob_item[i] --[使用(容器→元素)]--> PyObject (引用)
- list.sort() --[触发(排序→比较)]--> 元素.__lt__
- list.append() --[触发(扩容→分配)]--> PyMem_Realloc

【示例】
```python
lst = [1, 2, 3]
lst.append(4)       # [1, 2, 3, 4]
lst.insert(0, 0)    # [0, 1, 2, 3, 4]
lst.pop()           # [0, 1, 2, 3]
lst.sort(reverse=True)  # [3, 2, 1, 0]
```

╔═══════════════════════════════════════════════════════════╗
║  【数据类型】元组 tuple                                    ║
║  编号: E008 | 来源: 提取清单C031                         ║
╚═══════════════════════════════════════════════════════════╝

【定义】 元组是不可变、有序、可重复的元素序列，底层为固定长度PyObject*指针数组，因不可变而可哈希(若元素均可哈希)。

【结构】"它长什么样？"
- PyTupleObject: {ob_refcnt, ob_type, ob_size, ob_item[1](柔性数组成员)}
- 固定大小: 无allocated字段(创建时大小即固定)
- 空元组: 全局单例 PyTupleObject*, 所有()指向同一对象

【时序】"它按什么顺序动？"
- 所有操作返回新对象(无原地修改)
- 拼接(t1+t2): 分配新PyTupleObject → 拷贝t1+t2的引用(INCREF)
- 成员检查(x in tup): 线性扫描O(n)
- 拆包(a, b = tup): 逐元素绑定到新名字

【实体】"它的最小数据单元？"
- ob_item[]: 固定长度PyObject*指针数组

【边界】"它在哪里交出控制权？"
- 用作dict key: 调用tuple.__hash__, 因不可变hash可缓存
- 用作函数参数/返回值: 不可变性保证调用者无法被调用者修改

【内部关联】
- tuple --[配对(不可变→可哈希)]--> dict.set (hashable要求)
- a,b = tup --[触发(拆包→绑定)]--> 名字绑定(name binding)

【示例】
```python
t = (1, 2, 3)
a, b, c = t          # 拆包
d = {(1, 2): "point"}  # tuple作dict key
e = ()               # 指向空元组单例
```

╔═══════════════════════════════════════════════════════════╗
║  【数据类型】字典 dict                                     ║
║  编号: E009 | 来源: 提取清单C032+C035                     ║
╚═══════════════════════════════════════════════════════════╝

【定义】 字典是键值对映射，基于开放寻址哈希表实现，Python 3.6+保留插入顺序(Python 3.7+正式保证)，键必须可哈希，查找/插入/删除均摊O(1)。

【结构】"它长什么样？"
- 紧凑实现(PEP 412 / dict): ma_keys(PyDictKeysObject) + ma_values(PyObject** 数组)
- PyDictKeysObject: dk_refcnt + dk_size(哈希表大小) + dk_nentries(条目数) + dk_indices(索引数组 char[dk_size]) + dk_entries[](PyDictKeyEntry数组)
- PyDictKeyEntry: me_hash + me_key + me_value
- 开放寻址: index = hash(key) & (dk_size-1), 冲突时线性探测 dk_indices
- 插入顺序: 新条目追加到dk_entries末尾

【时序】"它按什么顺序动？"
- 查找(d[key]): hash(key) → 索引 → 比对me_key(先is后==) → 返回me_value
- 插入(d[key]=val): hash → 索引 → 空白处写入 → 若负载>2/3则扩容(x2)
- 删除(del d[key]): 标记为DKIX_DUMMY(墓碑), 不立即缩容
- 遍历(for k in d): 按dk_entries顺序(插入顺序)
- 合并(d1|d2): 创建新dict, 先拷贝d1再插入d2条目

【实体】"它的最小数据单元？"
- dk_indices: 索引数组, 存储entries索引(>=0)或FREE(-1)或DUMMY(-2)
- dk_entries: 紧凑键值对数组(PyDictKeyEntry[])
- me_hash: 预存hash值避免重复计算

【边界】"它在哪里交出控制权？"
- hash计算: 调用key.__hash__(), 非恒定时间
- 哈希冲突: 退化到O(n)扫描
- 扩容: 内存重新分配(所有条目重新哈希到新表)
- 键比较: 调用key.__eq__, 用户定义可能开销不可预知

【内部关联】
- dict[d[key]] --[触发(查找→哈希)]--> key.__hash__
- dk_entries[] --[包含(表→键值对)]--> PyDictKeyEntry
- dk_indices --[使用(索引→条目位置)]--> dk_entries

【薄概念合并】 C035(hash) 是dict操作的核心前置条件。

【示例】
```python
d = {"a": 1, "b": 2}
d["c"] = 3
print(d)           # {'a': 1, 'b': 2, 'c': 3} (保持插入顺序)
print(d.get("z", 0))  # 0
d1 = {"x": 9}
print(d | d1)      # {'a': 1, 'b': 2, 'c': 3, 'x': 9}
```

╔═══════════════════════════════════════════════════════════╗
║  【数据类型】集合 set / frozenset                          ║
║  编号: E010 | 来源: 提取清单C033+C034                     ║
╚═══════════════════════════════════════════════════════════╝

【定义】 set: 无序、可变、不重复的元素集合，基于哈希表(PySetObject), 支持集合运算(交/并/差/对称差); frozenset: 不可变版本，可哈希。

【结构】"它长什么样？"
- PySetObject: {ob_refcnt, ob_type, fill(活跃+虚拟), used(活跃), mask, table(setentry*)}
- setentry: {hash, key(PyObject*)} — 比dict少一个value
- 开放寻址: 与dict共享核心哈希逻辑(setobject.c)
- 运算: 交(&), 并(|), 差(-), 对称差(^)均创建新set/frozenset

【时序】"它按什么顺序动？"
- 添加(s.add(x)): hash → 索引 → 写入或去重
- 成员检查(x in s): hash → 索引 → 比对(先is后==)
- 集合运算: 遍历较小集合 → 在较大集合查找 → 构建结果
- forzenset: 所有操作同set但无变异操作

【实体】"它的最小数据单元？"
- table: setentry数组(开放寻址哈希表)
- setentry.key: 元素对象指针
- setentry.hash: 预存hash值

【边界】"它在哪里交出控制权？"
- 同dict: hash计算, 冲突退化, 扩容重哈希
- 元素必须是可哈希对象

【内部关联】
- set --[使用(表结构→哈希)]--> 开放寻址哈希表(与dict共享)
- frozenset --[配对(不可变→可哈希)]--> 可作为dict key/set元素

【示例】
```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a & b)    # {2, 3}
print(a | b)    # {1, 2, 3, 4}
print(a - b)    # {1}
fs = frozenset([1, 2, 3])
d = {fs: "key"}  # frozenset可作dict key
```

╔═══════════════════════════════════════════════════════════╗
║  【协议】容器协议                                        ║
║  编号: E011 | 来源: 提取清单C036                         ║
╚═══════════════════════════════════════════════════════════╝

【定义】 Python容器对象通过实现 __len__/__getitem__/__setitem__/__contains__ 魔术方法参与通用容器操作，遵循鸭子类型(duck typing)思想：不要求显式继承，只要求实现特定方法。

【结构】"它长什么样？"
- __len__(self) → len(x): 返回容器元素计数
- __getitem__(self, key) → x[i]: 按索引/键取值
- __setitem__(self, key, value) → x[i]=v: 按索引/键设值
- __delitem__(self, key) → del x[i]: 按索引/键删除
- __contains__(self, item) → item in x: 成员检测, 未实现则退化到__iter__扫描
- __reversed__(self) → reversed(x): 获取反向迭代器
- 自定义容器: 实现以上方法即可与len(), in, for等内置语法协同工作

【时序】"它按什么顺序动？"
- for x in obj: 调用 obj.__iter__() → 若未实现则 obj.__getitem__(0), __getitem__(1)... 直到IndexError

【实体】"它的最小数据单元？"
- 无固定实体维度(协议本身就是接口规范)

【边界】"它在哪里交出控制权？"
- 协议依赖鸭子类型: 运行时检查方法存在性, 无编译时保证
- 未实现__iter__时: for循环退化为O(n²)的__getitem__扫描

【内部关联】
- len() --[触发(长度查询→协议)]--> __len__
- for x in obj --[触发(遍历→一级:__iter__ 二级:__getitem__)]--> 迭代协议 / 序列协议

【示例】
```python
class MyList:
    def __init__(self):
        self._data = []
    def __getitem__(self, i):
        return self._data[i]
    def __len__(self):
        return len(self._data)
    def append(self, v):
        self._data.append(v)

ml = MyList()
ml.append(1); ml.append(2)
print(len(ml))     # 2 (调用__len__)
print(ml[0])       # 1 (调用__getitem__)
for x in ml:       # 遍历: 无__iter__, 退化__getitem__(0), __getitem__(1)...
    print(x)
```
