╔═══════════════════════════════════════════════════════════╗
║  【控制结构】条件分支 if/elif/else                         ║
║  编号: E012 | 来源: 提取清单C040                         ║
╚═══════════════════════════════════════════════════════════╝

【定义】 基于表达式布尔值(Truth Value Testing)的条件分支语句，按顺序测试条件，执行首个为True的分支。

【结构】"它长什么样？"
- if <expr>: 测试expr的真值(调用bool(expr), 实际调用expr.__bool__或__len__)
- elif/else: 互斥分支链, 最多一个分支被执行
- 三元表达式: x if cond else y (表达式形式)
- 短路求值: and/or表达式在确定结果时即停止求值

【时序】"它按什么顺序动？"
- if cond1: 测试cond1 → True: 执行body1 → 跳过剩余elif/else → 退出
- elif cond2: cond1为False时继续 → 测试cond2 → True: 执行body2 → 退出
- else: 所有条件为False时执行else body
- 短路: x and y → x为False时不计算y; x or y → x为True时不计算y

【实体】"它的最小数据单元？"
- 真值测试规则: False/None/0/0.0/""/[]/{}/()/set() 为假; 其余为真
- 自定义真值: __bool__ → 若未定义 → __len__(返回0为假)

【边界】"它在哪里交出控制权？"
- 条件表达式求值: 调用__bool__/__len__, 可能触发任意用户代码

【示例】
```python
x = 5
if x > 0:
    print("正数")
elif x < 0:
    print("负数")
else:
    print("零")

# 三元表达式
s = "even" if x % 2 == 0 else "odd"

# 短路求值
a = None
print(a and a.upper())  # None (a为假, 不计算a.upper())
b = "hello"
print(b and b.upper())  # HELLO
```

╔═══════════════════════════════════════════════════════════╗
║  【控制结构】循环 for / while                              ║
║  编号: E013 | 来源: 提取清单C041+C042+C043                ║
╚═══════════════════════════════════════════════════════════╝

【定义】 for: 遍历可迭代对象逐个消费元素的确定性循环; while: 条件驱动的非确定性循环。两者均支持break(跳出)/continue(跳过当前)/else(正常结束运行)。

【结构】"它长什么样？"
- for <var> in <iterable>: 获取iterable的迭代器 → 逐次调用next() → StopIteration结束
- while <cond>: 每次迭代前测试cond → True执行body → False退出
- break: 立即跳出最近的循环
- continue: 立即跳到下一次迭代(重新测试条件)
- else: 循环未被break中断时执行(包括零次迭代)

【时序】"它按什么顺序动？"
- for循环:
  1. iter(iterable)获取迭代器
  2. next(iterator)取下一个值
  3. 绑定到循环变量
  4. 执行body
  5. 重复2-4直到StopIteration
  6. 若无break → 执行else子句
- while循环:
  1. 测试cond
  2. True → 执行body
  3. body中若break → 跳出(不执行else)
  4. body中若continue → 回到1
  5. body正常结束 → 回到1
  6. cond为False → 执行else子句

【实体】"它的最小数据单元？"
- for循环隐式持有迭代器对象(栈上的临时引用)
- range对象: {start, stop, step}, 惰性产生整数

【边界】"它在哪里交出控制权？"
- next()调用: 触发迭代器.__next__, 可能涉及I/O或用户逻辑
- 无限循环: while True无break则永不退出
- 迭代过程中修改被迭代对象: 可能导致未定义行为

【内部关联】
- for --[触发(遍历→取值)]--> iterable.__iter__ → iterator.__next__
- break --[触发(终止→跳出)]--> 循环体外第一条语句
- continue --[触发(跳过→下次)]--> 循环条件测试
- else --[配对(循环→正常结束)]--> 未被break中断

【薄概念合并】 C041+C042+C043 统一为循环控制结构。

【示例】
```python
for i in range(3):
    if i == 1:
        continue
    print(i)        # 0, 2
else:
    print("done")   # done (未被break)

n = 3
while n > 0:
    n -= 1
    if n == 1:
        break
    print(n)        # 2
else:
    print("while done")  # 未执行(被break)
```

╔═══════════════════════════════════════════════════════════╗
║  【控制结构】模式匹配 match/case                           ║
║  编号: E014 | 来源: 提取清单C044                         ║
╚═══════════════════════════════════════════════════════════╝

【定义】 Python 3.10+引入的结构化模式匹配，支持值匹配、序列解构、映射解构、类匹配、守卫条件(if)，是增强版switch。

【结构】"它长什么样？"
- match <subject>: — 待匹配的主题表达式(只计算一次)
- case <pattern> [if guard]: — 模式+可选守卫
- 模式类型:
  - 字面值模式: case 1 / case "hello" / case True
  - 变量捕获: case x (匹配一切, 绑定到x)
  - 解构模式: case [a, b] / case (a, b) / case {"key": v}
  - 类模式: case Point(x=0, y=0)
  - 通配符: case _ (匹配一切, 不绑定)
  - 或模式: case 1 | 2 | 3
  - 守卫: case x if x > 0

【时序】"它按什么顺序动？"
- 首次匹配: 按case顺序测试, 首个成功的case执行后退出(无穿透)
- 无匹配: 无默认分支时静默通过(不抛异常)

【实体】"它的最小数据单元？"
- 编译器生成的匹配决策树(字节码级别: MATCH_SEQUENCE/MATCH_KEYS/MATCH_CLASS...)

【边界】"它在哪里交出控制权？"
- 类匹配: 调用__match_args__获取属性列表, 调用属性取值触发用户代码
- 映射匹配: 依赖__getitem__或属性访问

【示例】
```python
def analyze(v):
    match v:
        case 0:
            return "zero"
        case [a, b] if a == b:
            return f"equal pair: {a}"
        case [a, b]:
            return f"pair: {a}, {b}"
        case {"name": n}:
            return f"named: {n}"
        case _:
            return "unknown"

print(analyze([1, 1]))    # equal pair: 1
print(analyze([1, 2]))    # pair: 1, 2
print(analyze({"name": "L"}))  # named: L
```
