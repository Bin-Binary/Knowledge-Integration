### 题目1：实现一个双向迭代器

创建一个`BidirectionalIterator`类，支持正向（`next()`）和反向（`prev()`）迭代。

```python
# 参考答案
class BidirectionalIterator:
    def __init__(self, items):
        self.items = items
        self.index = -1
    
    def __iter__(self):
        return self
    
    def __next__(self):
        self.index += 1
        if self.index >= len(self.items):
            raise StopIteration
        return self.items[self.index]
    
    def prev(self):
        self.index -= 1
        if self.index < 0:
            raise StopIteration
        return self.items[self.index]

# 测试
bi = BidirectionalIterator([1, 2, 3])
print(next(bi))  # 1
print(next(bi))  # 2
print(bi.prev()) # 1
print(next(bi))  # 2
print(next(bi))  # 3
```

### 题目2：实现一个懒加载字典

创建`LazyDict`，键值对在首次访问时通过函数计算。

```python
# 参考答案
class LazyDict:
    def __init__(self):
        self._computed = {}
        self._factories = {}
    
    def set_factory(self, key, factory):
        """设置值工厂函数"""
        self._factories[key] = factory
    
    def __getitem__(self, key):
        if key not in self._computed:
            if key in self._factories:
                self._computed[key] = self._factories[key]()
            else:
                raise KeyError(key)
        return self._computed[key]
    
    def __contains__(self, key):
        return key in self._factories or key in self._computed

# 测试
lazy = LazyDict()
lazy.set_factory('expensive', lambda: sum(range(1000000)))
print('expensive' in lazy)  # True
value = lazy['expensive']   # 此时才计算
print(value)
```

### 题目3：实现一个可验证的属性描述符

创建`ValidatedAttribute`描述符，支持类型检查和自定义验证函数。

```python
# 参考答案
class ValidatedAttribute:
    def __init__(self, type_=None, validator=None):
        self.type = type_
        self.validator = validator
        self.name = None
    
    def __set_name__(self, owner, name):
        self.name = name
    
    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        return obj.__dict__.get(self.name)
    
    def __set__(self, obj, value):
        # 类型检查
        if self.type and not isinstance(value, self.type):
            raise TypeError(f"{self.name} 必须是 {self.type.__name__} 类型")
        
        # 自定义验证
        if self.validator:
            self.validator(value)
        
        obj.__dict__[self.name] = value

# 测试

    price = ValidatedAttribute(
        type_=(int, float),
        validator=lambda x: x > 0 or ValueError("价格必须为正")
    )
    
    def __init__(self, price):
        self.price = price

p = Product(19.99)
```

### 题目4：实现一个计数上下文管理器

创建`Counter`上下文管理器，统计代码块执行次数和总时间。

```python
# 参考答案
import time

class Counter:
    _counts = {}
    _times = {}
    
    def __init__(self, name):
        self.name = name
        self.start_time = None
    
    def __enter__(self):
        self._counts[self.name] = self._counts.get(self.name, 0) + 1
        self.start_time = time.perf_counter()
        return self
    
    def __exit__(self, exc_type, exc_val, exc_tb):
        elapsed = time.perf_counter() - self.start_time
        self._times[self.name] = self._times.get(self.name, 0) + elapsed
        return False
    
    @classmethod
    def stats(cls, name):
        """获取统计信息"""
        return {
            'count': cls._counts.get(name, 0),
            'total_time': cls._times.get(name, 0),
            'avg_time': cls._times.get(name, 0) / cls._counts.get(name, 1)
        }

# 测试
for _ in range(3):
    with Counter('process'):
        time.sleep(0.1)

print(Counter.stats('process'))
# {'count': 3, 'total_time': 0.30, 'avg_time': 0.10}
```

### 题目5：实现一个可序列化的可哈希类

创建`SerializableHashable`基类，支持JSON序列化和哈希。

```python
# 参考答案
import json
from abc import ABC, abstractmethod

class SerializableHashable(ABC):
    @abstractmethod
    def to_dict(self):
        """转换为字典"""
        pass
    
    @classmethod
    @abstractmethod
    def from_dict(cls, d):
        """从字典创建"""
        pass
    
    def to_json(self):
        """序列化为JSON"""
        return json.dumps(self.to_dict())
    
    @classmethod
    def from_json(cls, s):
        """从JSON反序列化"""
        return cls.from_dict(json.loads(s))
    
    def __eq__(self, other):
        if not isinstance(other, self.__class__):
            return NotImplemented
        return self.to_dict() == other.to_dict()
    
    def __hash__(self):
        return hash(json.dumps(self.to_dict(), sort_keys=True))

# 测试
class Point(SerializableHashable):
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    def to_dict(self):
        return {'x': self.x, 'y': self.y}
    
    @classmethod
    def from_dict(cls, d):
        return cls(d['x'], d['y'])

p1 = Point(1, 2)
p2 = Point(1, 2)
print(p1 == p2)  # True
print(hash(p1) == hash(p2))  # True
print(p1.to_json())  # '{"x": 1, "y": 2}'
```

## 十一、协议的解释力——用协议重新理解Python

协议为Python的许多"魔法"行为提供了统一的解释框架。以下表格展示了协议如何解释常见Python行为。

| 行为/现象 | 协议解释 | 底层机制 | 示例 |
|----------|---------|---------|------|
| `for x in obj` | 迭代器协议 | `iter(obj)` → `__iter__()` → `__next__()` 循环 | 任何可迭代对象 |
| `len(obj)` | Sized协议 | 调用 `obj.__len__()` | len([1,2,3]) → 3 |
| `item in obj` | Container协议 | 优先 `__contains__`，降级到遍历 | `'a' in 'abc'` |
| `obj[key]` | `__getitem__`协议 | 调用 `obj.__getitem__(key)` | dict['key'] |
| `obj[key] = val` | `__setitem__`协议 | 调用 `obj.__setitem__(key, val)` | list[0] = 1 |
| `obj(args)` | Callable协议 | 调用 `obj.__call__(args)` | 装饰器、仿函数 |
| `hash(obj)` | Hashable协议 | 调用 `obj.__hash__()` | dict key, set元素 |
| `obj1 == obj2` | 相等协议 | 调用 `obj1.__eq__(obj2)` | 自定义比较 |
| `with obj:` | 上下文管理器协议 | `__enter__()` → 执行 → `__exit__()` | 文件、锁管理 |
| `obj.attr` | 描述符协议 | 查找链：数据描述符 → 实例字典 → 非数据描述符 | property, classmethod |
| `str(obj)` | 字符串协议 | 调用 `obj.__str__()` 或 `obj.__repr__()` | print(obj) |
| `bool(obj)` | 布尔协议 | 调用 `obj.__bool__()` 或 `len(obj)` | if obj: |
| `abs(obj)` | 绝对值协议 | 调用 `obj.__abs__()` | 自定义数值类型 |
| `obj + other` | 算术协议 | 调用 `obj.__add__(other)` | 运算符重载 |
| `obj[key1:key2]` | 切片协议 | 调用 `obj.__getitem__(slice(key1, key2))` | list[1:3] |
| `iter(obj)` | 迭代器协议 | 调用 `obj.__iter__()` | 获取迭代器 |
| `next(iterator)` | 迭代器协议 | 调用 `iterator.__next__()` | 手动迭代 |
| `obj[::2]` | 切片协议 | 调用 `obj.__getitem__(slice(None, None, 2))` | 步长切片 |
| `obj @ matrix` | 矩阵乘法协议 | 调用 `obj.__matmul__(matrix)` | NumPy矩阵乘法 |
| `reversed(obj)` | 反转协议 | 调用 `obj.__reversed__()` 或反向迭代 | list反转 |
| `obj[key]`（删除） | `__delitem__`协议 | 调用 `obj.__delitem__(key)` | del dict['key'] |
| `obj.real` | 复数协议 | 调用 `obj.__real` 属性 | 复数实部 |
| `format(obj, spec)` | 格式化协议 | 调用 `obj.__format__(spec)` | f"{obj:.2f}" |

### 协议与类型系统

| 类型检查方法 | 检查内容 | Python推荐方式 |
|------------|---------|--------------|
| `isinstance(obj, SomeABC)` | 协议支持（虚拟子类） | `isinstance(obj, Iterable)` |
| `hasattr(obj, '__iter__')` | 方法存在 | 较低层级，但不推荐 |
| `type(obj) is SomeType` | 精确类型匹配 | 过于严格，不推荐 |
| `isinstance(obj, SomeClass)` | 继承关系 | 传统方式，支持ABC |
| EAFP（先调用） | 实际行为可用 | `try: iter(obj)...` |

**Python之禅**："Easier to Ask for Forgiveness than Permission"（请求宽恕比请求许可更容易）——这正是协议的精神：**不问对象"你是不是迭代器"，而是尝试迭代它，如果不能就抛异常。**

```python
# 示例：EAFP协议使用
def process_iterable(obj):
    """EAFP风格：先尝试，再处理异常"""
    try:
        for item in obj:
            print(item)
    except TypeError:
        print(f"{obj} 不是可迭代对象")

# LBYL风格（不推荐）
def process_iterable_lbyl(obj):
    """LBYL风格：先检查，再执行"""
    if hasattr(obj, '__iter__'):
        for item in obj:
            print(item)
    else:
        print(f"{obj} 不是可迭代对象")
```

## 十二、总结——协议的哲学

### 协议是Python对象模型的灵魂

本文系统梳理了Python的核心协议，揭示了它们背后的工作机制和设计哲学。让我们总结关键要点：

**1. 协议的本质**
- 协议 = 方法名称集合 + 行为约定
- 非强制、运行时检测、最小承诺
- 鸭类型："如果它走起来像鸭子，那它就是鸭子"

**2. 核心协议矩阵**

| 协议 | 方法 | 赋予能力 | ABC类 |
|------|------|---------|-------|
| 迭代器 | `__iter__`, `__next__` | 可被for循环 | `Iterator` |
| 可迭代 | `__iter__` | 可创建迭代器 | `Iterable` |
| Sized | `__len__` | 支持`len()` | `Sized` |
| Container | `__contains__` | 支持`in` | `Container` |
| Sequence | `__getitem__` + `__len__` | 索引+切片+迭代 | `Sequence` |
| Mapping | `__getitem__` + `__iter__` | 键值访问 | `Mapping` |
| Callable | `__call__` | 可像函数调用 | `Callable` |
| Hashable | `__hash__` + `__eq__` | 可作dict key | `Hashable` |
| Context Manager | `__enter__`, `__exit__` | 资源管理 | `ContextManager` |
| Descriptor | `__get__`, `__set__`, `__delete__` | 属性控制 | — |

**3. 协议的设计原则**
- **最小接口**：只实现需要的方法
- **行为优先**：关注对象能做什么，而非是什么
- **组合优于继承**：协议可自由组合
- **验证而非强制**：ABC提供验证，不强制实现

**4. 协议的实现层次**

```
应用层：高阶Python代码（自定义类、装饰器等）
    ↓
协议层：特殊方法定义（__iter__, __call__等）
    ↓
ABC层：collections.abc形式化验证
    ↓
类型槽层：PyTypeObject的tp_iter, tp_call等槽位
    ↓
解释器层：字节码执行、方法调用
    ↓
运行时层：对象内存布局、方法查找
```

**5. 从协议视角重新理解**

- **迭代器协议**解释了为何`for x in obj:`能工作
- **容器协议**解释了为何`len()`、`in`、索引访问能统一
- **可调用协议**解释了装饰器和仿函数的原理
- **哈希协议**解释了dict key和set元素的要求
- **上下文管理器协议**解释了`with`语句的资源管理
- **描述符协议**解释了`property`、`classmethod`、`staticmethod`的实现

### 协议与其他文章的关联

回到文章开头提到的知识整合：

- **《容器篇》（三）**：容器协议（`__len__`、`__contains__`、`__getitem__`）是容器行为的基础
- **《迭代器篇》（六）**：迭代器协议是生成器和迭代的核心机制
- **《OOP篇》（七）**：描述符协议是属性访问和类方法的底层实现
- **《异常篇》（九）**：上下文管理器协议提供了基于异常的资源管理

**协议是这些知识点的统一框架**，它们不是孤立的语法特性，而是通过协议这个底层机制联系在一起。

### 实践建议

1. **优先实现协议而非继承具体类**
2. **使用ABC验证协议完整性**
3. **遵循协议契约（如哈希一致性）**
4. **理解协议优先级（如数据描述符 > 实例字典）**
5. **组合协议创建灵活类型**
6. **在库设计中清晰文档协议要求**

Python的协议系统展示了Python设计哲学的精髓：**简洁、灵活、行为优先**。通过理解协议，你不仅掌握了Python的高级特性，还深入理解了Python对象模型的核心思想。协议让Python成为一门"约定优于配置"的语言——只要你遵循约定，语言就会赋予你强大的能力。
