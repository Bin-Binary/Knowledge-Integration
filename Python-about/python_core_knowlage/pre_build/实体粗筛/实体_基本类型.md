╔═══════════════════════════════════════════════════════════╗
║  【数据类型】整数 int                                      ║
║  编号: E002 | 来源: 提取清单C010+C013                     ║
╚═══════════════════════════════════════════════════════════╝

【定义】 Python整数为任意精度(big integer), 无溢出上限, 底层用30-bit每"digit"的数组存储(PyLongObject), bool是其子类。

【结构】"它长什么样？"
- 底层: PyLongObject {ob_refcnt, ob_type, ob_size(数组长度含符号), ob_digit[](uint30数组)}
- bool: PyLongObject的子类, True/False是单例, True.__class__.__bases__[0] == int
- 字面量: 十进制(42), 十六进制(0x2A), 八进制(0o52), 二进制(0b101010)
- 小整数池: CPython缓存[-5, 256]的int对象, 避免频繁创建

【时序】"它按什么顺序动？"
- 算术运算: 每次运算创建新int对象(不可变), CPython对加减乘法有fast path
- 溢出处理: 当30-bit digit溢出后, ob_digit数组扩容(重新分配内存)
- 除法: /返回float, //返回int(整除)
- 比较: ==/!=, <, <=, >, >= 逐digit比较

【实体】"它的最小数据单元？"
- ob_size: 负值表示负数(绝对值=digit数)
- ob_digit: uint30数组, 每个元素存储30-bit的"数字"(不是10进制digit)

【边界】"它在哪里交出控制权？"
- 超大整数运算: 时间复杂度O(n²) (n=位数), 可能显著耗时
- 内存: ob_digit数组动态分配, 超大数可能OOM
- 与C整数互转: PyLong_AsLong()溢出时抛OverflowError

【内部关联】
- int --[包含(类型→值)]--> ob_digit[]
- bool --[使用(子类→父类)]--> int (继承关系)
- int运算 --[触发(计算→新对象)]--> 新int对象

【示例】
```python
x = 10**100  # 任意精度, 无溢出
print(type(True))      # <class 'bool'>
print(issubclass(bool, int))  # True
print(True + 1)        # 2
```

╔═══════════════════════════════════════════════════════════╗
║  【数据类型】浮点数 float                                  ║
║  编号: E003 | 来源: 提取清单C011                         ║
╚═══════════════════════════════════════════════════════════╝

【定义】 Python浮点数为IEEE 754双精度64位二进制浮点数, 对应C语言double类型, 不可变。

【结构】"它长什么样？"
- 64位布局: 1位符号 + 11位指数(bias=1023) + 52位尾数(隐含前导1)
- PyFloatObject: {ob_refcnt, ob_type, ob_fval(C double)}
- 特殊值: float('inf'), float('-inf'), float('nan')

【时序】"它按什么顺序动？"
- 运算: 通过CPU FPU执行, 创建新PyFloatObject

【实体】"它的最小数据单元？"
- ob_fval: C double (64-bit IEEE 754)

【边界】"它在哪里交出控制权？"
- 精度丢失: 小数二进制无法精确表示(如0.1是无限循环二进制小数)
- nan比较: nan != nan (IEEE 754规定)
- 超出double范围: 自动转为±inf

【内部关联】
- float运算 --[触发(浮点运算→CPU FPU)]--> IEEE 754指令

【示例】
```python
print(0.1 + 0.2)         # 0.30000000000000004
print(0.1 + 0.2 == 0.3)  # False
import math
print(math.isinf(float('inf')))  # True
```

╔═══════════════════════════════════════════════════════════╗
║  【数据类型】字符串 str                                    ║
║  编号: E004 | 来源: 提取清单C020+C023+C025+C113          ║
╚═══════════════════════════════════════════════════════════╝

【定义】 Python字符串为Unicode码点不可变序列, Python 3.14使用灵活字符串表示(PEP 393), 根据最大码点自动选择1/2/4字节每字符内部存储。

【结构】"它长什么样？"
- PyASCIIObject/PyCompactUnicodeObject/PyUnicodeObject 三态并存
- state字段: kind(1=Latin1, 2=UCS2, 4=UCS4) + compact(是否紧凑存储) + ascii(是否纯ASCII)
- 紧凑模式: 数据紧跟在结构体后(无额外指针), 非紧凑有wstr指针
- 切片: 创建新str对象, 引用原字符串数据(共享内存)
- 字面量: 单引号/双引号/三引号, r前缀(raw), f前缀(format), b前缀(bytes)

【时序】"它按什么顺序动？"
- 拼接(str1+str2): 计算总长度 → 分配新内存 → 逐字符拷贝 → 返回新str
- 切片(str[start:stop:step]): 计算新长度 → 分配内存 → 按step拷贝码点
- 编码(str.encode()): 遍历每个码点 → 映射到目标编码(UTF-8/GBK/latin-1)
- 格式化(f"{x}"): 逐段评估表达式 → 转字符串 → 拼接 → 返回新str
- 驻留(intern): CPython自动驻留短字符串(长度≤4096且符合标识符规则)

【实体】"它的最小数据单元？"
- 码点(code point): 0~0x10FFFF的Unicode整数
- 内部存储单元: 取决于kind (1字节/2字节/4字节)
- 元数据: length + hash(惰性计算) + state

【边界】"它在哪里交出控制权？"
- 编码/解码: 通过标准库codecs调用C编码器
- 正则表达式: 调用re模块(基于C的SRE引擎)
- f-string表达式求值: 每次执行时重新求值(不是编译时常量)
- 字符串驻留池: 全局字典存储驻留字符串(内存换查找速度)

【内部关联】
- str.encode() --[使用(字符串→编码器)]--> codecs模块
- f-string --[触发(表达式求值→变量)]--> 当前作用域
- 切片[::] --[触发(子序列→新对象)]--> 新str对象(共享底层数据)

【薄概念合并】 C023(编码解码) + C025(切片) + C113(f-string) 均属于字符串操作子维度, 独立成卡不增新关系边。

【示例】
```python
s = "Hello 世界"
print(s.encode('utf-8'))          # b'Hello \xe4\xb8\x96\xe7\x95\x8c'
print(b'\xe4\xb8\x96'.decode())   # 世
print(s[0:5])                     # Hello
name = "Python"
print(f"Hello {name}")            # Hello Python
```

╔═══════════════════════════════════════════════════════════╗
║  【数据类型】二进制类型 bytes / bytearray                   ║
║  编号: E005 | 来源: 提取清单C021+C022                     ║
╚═══════════════════════════════════════════════════════════╝

【定义】 bytes: 0-255整数的不可变序列; bytearray: 0-255整数的可变序列; 均不携带编码信息。

【结构】"它长什么样？"
- PyBytesObject: {ob_refcnt, ob_type, ob_size, ob_shash, ob_sval[](1字节数组)}
- PyByteArrayObject: {ob_refcnt, ob_type, ob_size, ob_start, ob_bytes(1字节数组), ob_alloc(分配容量)}
- 字面量: b"hello", b'\x00\xff', B"bytes"

【时序】"它按什么顺序动？"
- bytes: 不可变, 所有操作返回新对象
- bytearray: 可变, append/extend/insert等原地修改(可能触发realloc扩容)
- 与str转换: bytes.decode(encoding) → str; str.encode(encoding) → bytes

【实体】"它的最小数据单元？"
- ob_sval: C char数组(0-255)
- ob_alloc(bytearray): 分配的总容量≥ob_size

【边界】"它在哪里交出控制权？"
- 网络/文件I/O: bytes是网络传输和文件二进制模式的默认数据类型
- C扩展: 许多C函数期望const char* (bytes可直接传递)

【内部关联】
- bytes --[配对(二进制↔文本)]--> str (通过编解码)
- bytearray --[触发(扩容→realloc)]--> PyMem_Realloc

【示例】
```python
data = b'hello\x00world'
print(len(data))    # 11
buf = bytearray(5)
buf[0] = 65
print(buf)          # bytearray(b'A\x00\x00\x00\x00')
```

╔═══════════════════════════════════════════════════════════╗
║  【数据类型】None / 运算符综合                              ║
║  编号: E006 | 来源: 提取清单C024+C014                     ║
╚═══════════════════════════════════════════════════════════╝

【定义】 None是NoneType的单例对象, 表示"无值"; Python运算符通过魔术方法实现, 可被用户类型重载。

【结构】"它长什么样？"
- NoneType: 没有公开构造函数, None是全局单例
- 运算符映射: + → __add__/__radd__, - → __sub__, * → __mul__, / → __truediv__, // → __floordiv__, % → __mod__, ** → __pow__, == → __eq__, is → 指针比较(不可重载)
- 复合赋值(a+=b): 对可变对象原地修改(__iadd__), 对不可变对象等同于a=a+b

【时序】"它按什么顺序动？"
- 二元运算: 左操作数.__op__(右) → 若返回NotImplemented → 右.__rop__(左)
- 比较链: a < b < c 等价于 a < b and b < c (b只计算一次)

【实体】"它的最小数据单元？"
- None: 单例, sizeof(PyObject)(最小PyObject结构)

【边界】"它在哪里交出控制权？"
- None用于"无值"语义: 函数无return(隐式返回None), dict.get()未找到键, 哨兵值
- 运算符重载: 调用用户代码, 不可预知复杂度

【示例】
```python
print(None is None)   # True (单例)
print(type(None))     # <class 'NoneType'>

# 比较链
x = 5
print(3 < x < 10)     # True, 等价于 3 < x and x < 10
```
