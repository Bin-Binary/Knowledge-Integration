╔═══════════════════════════════════════════════════════════╗
║  【函数机制】函数定义与参数系统                            ║
║  编号: E015 | 来源: 提取清单C050+C051+C052+C057           ║
╚═══════════════════════════════════════════════════════════╝

【定义】 def语句在编译时创建PyFunctionObject(PyCodeObject + 闭包环境), 运行时调用时压入新栈帧执行字节码; 函数是一等公民(可赋值、传参、返回)。

【结构】"它长什么样？"
- PyFunctionObject: {func_code(PyCodeObject*), func_globals(dict*), func_defaults(tuple*), func_closure(tuple*), func_dict(dict*), func_name(str*), func_qualname(str*)}
- PyCodeObject: co_code(字节码), co_consts(常量), co_varnames(局部变量名), co_argcount(参数数), co_kwonlyargcount
- def执行流程: def编译时生成LOAD_CONST(代码对象)+MAKE_FUNCTION → 运行时创建函数对象 → 绑定到函数名
- lambda: 相当于匿名def, 限制单表达式(无语句), 其余机制完全相同

【时序】"它按什么顺序动？"
- 函数调用(call序列):
  1. 创建栈帧 PyFrameObject
  2. 参数绑定: 位置参数 → 关键字参数 → *args填充 → **kwargs填充 → 默认值补充
  3. 开始执行字节码(逐条分派)
  4. 遇到return → 设置返回值 → 清理帧 → 返回调用者
  5. 遇到异常: 未捕获则向上冒泡
- 参数规则:
  - 位置参数放最前
  - 默认参数值在def被执行时计算一次(非每次调用)
  - *args收集多余位置参数为元组
  - **kwargs收集多余关键字参数为字典
  - keyword-only参数: 在*后面的参数必须用关键字传递
  - positional-only参数: 在/前面的参数只能用位置传递(Python 3.8+)

【实体】"它的最小数据单元？"
- func_code: PyCodeObject指针
- func_globals: 模块全局名字空间(函数创建时捕获)
- func_defaults: 默认参数值元组(对应最后N个参数)
- func_closure: None或闭包Cell对象元组(记录自由变量)
- func_qualname: 完整限定名(含类名)

【边界】"它在哪里交出控制权？"
- 函数调用: 栈帧创建有最大深度限制(sys.getrecursionlimit()), 超出则RecursionError
- 默认值共享陷阱: 可变默认参数(def f(x=[]))在多次调用间共享同一对象
- C扩展调用: 穿越Python/C边界, GIL释放/持有的切换点
- 调用开销: Python函数调用比C函数慢1-2个数量级

【内部关联】
- PyFunctionObject.func_code --[配对(函数→字节码)]--> PyCodeObject
- func()调用 --[触发(调用→帧创建)]--> PyFrameObject
- *args --[触发(收集→聚合)]--> tuple
- **kwargs --[触发(收集→聚合)]--> dict

【薄概念合并】 C050(def)+C051(参数)+C052(return)+C057(lambda) 构成函数全生命周期。

【示例】
```python
def greet(name, greeting="Hello", *, punctuation="!"):
    return f"{greeting}, {name}{punctuation}"

print(greet("World"))                           # Hello, World!
print(greet("Python", punctuation="..."))       # Hello, Python...

# 可变默认参数陷阱
def bad_append(item, lst=[]):
    lst.append(item)
    return lst
print(bad_append(1))  # [1]
print(bad_append(2))  # [1, 2] (共享同一列表!)
```

║  【作用域机制】LEGB规则与闭包                              ║
║  编号: E016 | 来源: 提取清单C053+C054+C055+C056          ║
╚═══════════════════════════════════════════════════════════╝

【定义】 Python变量名解析遵循LEGB规则: Local(函数内)→Enclosing(外层函数)→Global(模块)→Built-in(内置名字空间)。闭包: 内部函数捕获外层函数变量的机制。

【结构】"它长什么样？"
- 名字空间(namespace): 名字到对象的映射, dict实现
- Local: 函数局部变量 → PyFrameObject.f_locals
- Enclosing: 外层函数的局部变量 → 通过func_closure中的Cell对象引用
- Global: 模块全局变量 → PyFrameObject.f_globals
- Built-in: 内置函数/异常 → builtins模块.__dict__
- Cell对象(PyCellObject): {ob_refcnt + ob_ref(PyObject*)}, 自由变量存储单元

【时序】"它按什么顺序动？"
- 变量读取: Local查→有则返回 → Enclosing查→有则返回 → Global查→有则返回 → Built-in查→有则返回 → NameError
- 变量赋值: 默认在当前局部作用域创建新变量(即使外层已有同名)
- global声明: 函数内用global x → 本函数内对x的赋值作用到模块全局
- nonlocal声明: 函数内用nonlocal x → 赋值作用到最近外层作用域中的x
- 闭包创建: 函数定义时, 编译器扫描自由变量 → 生成Cell对象 → func_closure持有

【实体】"它的最小数据单元？"
- PyCellObject: ob_ref(PyObject*), 自由变量的间接引用
- func_closure: tuple of PyCellObject*
- f_locals: dict (通常惰性创建)
- f_globals: dict (函数创建时模块的__dict__)

【边界】"它在哪里交出控制权？"
- 名字未找到: NameError异常, 栈展开回溯
- 闭包捕获: 是捕获变量对象引用(非值复制), 内部函数修改可变对象对外可见
- 循环中创建闭包的经典陷阱: 变量捕获的是同一变量对象, 所有闭包共享最终值

【内部关联】
- 名字查找 --[触发(LEGB→查字典)]--> Local→Enclosing→Global→Built-in
- Cell.ob_ref --[使用(闭包→自由变量)]--> PyObject
- global x --[触发(重定向→全局)]--> func_globals["x"]
- nonlocal x --[触发(重定向→外层)]--> 外层func_closure中的Cell

【薄概念合并】 C053(LEGB)+C054(global)+C055(闭包)+C056(nonlocal) 同属作用域解析机制。

【示例】
```python
x = "global"
def outer():
    x = "outer"
    def inner():
        # nonlocal x  # 取消注释后修改outer的x
        print(x)      # "outer" (从Enclosing作用域找到)
    inner()
outer()

# 闭包陷阱
closures = []
for i in range(3):
    closures.append(lambda: print(i))
closures[0]()  # 2 (不是0! 所有闭包共享同一个i)
closures[1]()  # 2
closures[2]()  # 2

# 正确做法: 用默认参数捕获当前值
closures2 = []
for i in range(3):
    closures2.append(lambda i=i: print(i))
closures2[0]()  # 0
```

╔═══════════════════════════════════════════════════════════╗
║  【函数机制】常用内置函数                                  ║
║  编号: E017 | 来源: 提取清单C058                         ║
╚═══════════════════════════════════════════════════════════╝

【定义】 解释器预置的核心函数, C扩展实现, 提供基础操作: 类型创建/判断, 容器操作, 迭代辅助, I/O, 数学运算等。

【结构】"它长什么样？"
- 内置函数注册在builtins模块 → builtins.__dict__
- 类型判断: type(obj), isinstance(obj, cls), issubclass(sub, sup)
- 创建: int(), float(), str(), list(), tuple(), dict(), set(), bool()
- 迭代器: iter(), next(), reversed()
- 序列操作: len(), sorted(), reversed(), enumerate(), zip(), map(), filter()
- 数值: abs(), round(), pow(), divmod(), sum(), min(), max()
- 对象操作: id(), hash(), dir(), vars(), getattr(), setattr()
- I/O: print(), input(), open()
- 异步: __import__(), compile(), exec(), eval()

【时序】"它按什么顺序动？"
- len(obj): 调用 obj.__len__() → O(1)(通常)
- sorted(obj): 内部构建列表 → Timsort → 返回新列表
- map(fn, iterable): 惰性迭代器(不立即执行), 每次next()调fn
- filter(fn, iterable): 惰性迭代器, 仅当fn(x)为True时产出x
- zip(*iterables): 惰性迭代器, 逐元素配对, 以最短为界(可strict=True抛异常)
- enumerate(iterable, start=0): 惰性产生(index, item)对

【实体】"它的最小数据单元？"
- builtins模块: 固定的PyModuleObject, __dict__包含所有内置名字

【边界】"它在哪里交出控制权？"
- map/filter/zip/enumerate: 返回迭代器(惰性求值), 必须消费才能执行
- print(): 写入sys.stdout → 调用write() → 系统调用write(2)
- input(): 读sys.stdin → 调用readline() → 系统调用read(2) → 阻塞等待
- open(): 调用C库fopen → 系统调用open(2)
- exec()/eval(): 执行任意代码, 安全边界需要调用者自行确保

【示例】
```python
names = ["alice", "bob"]
for i, name in enumerate(names, 1):
    print(f"{i}: {name}")   # 1: alice  2: bob

squares = list(map(lambda x: x**2, range(5)))
print(squares)  # [0, 1, 4, 9, 16]

evens = list(filter(lambda x: x%2==0, range(10)))
print(evens)    # [0, 2, 4, 6, 8]

zipped = list(zip("ab", [1, 2]))
print(zipped)   # [('a', 1), ('b', 2)]
```
