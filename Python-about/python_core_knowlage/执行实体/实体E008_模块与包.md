# 执行实体: 模块与包

> Step 4 | N0→D1 | 突破维度: 结构

---

╔═══════════════════════════════════════════════════════════╗
║  【代码组织】module / import / package / __name__          ║
║  编号: E008 | 来源: C080-C086                            ║
╚═══════════════════════════════════════════════════════════╝

【定义】 模块(.py文件)是代码组织单元, 拥有独立全局名字空间(__dict__); 包是含__init__.py的目录; import系统通过sys.path执行查找→加载→缓存流程。

【冲突溯源】 N0→D1(统一对象模型: 模块也是PyModuleObject, 名字空间=dict映射), 突破维度: 结构

【设计内因】 D1工程目标: 模块化组织天然延伸对象模型——名称隔离=dict映射, 导入=创建模块对象+执行代码+缓存于sys.modules。
  通用困境:
  - (结构) 模块多次导入的副作用: 重复执行初始化代码会重置全局状态
  - (结构) 脚本vs库双身份: .py文件可能被直接运行或as import

  SC1(结构): [归属困境: 重复加载副作用] import两次模块→若重新执行代码→全局变量/注册/连接被覆盖 [幂等性约束] → 选择: sys.modules字典缓存已加载模块: 首次import→写入→后续import直接返回缓存(不重执行) | 代价: 无法简单"重启"; 需importlib.reload()

  SC2(结构): [归属困境: 脚本vs库] .py文件直接运行时要执行main, 导入时不应执行初始化打印 [入口分化约束] → 选择: __name__变量: python spam.py→"__main__"; import spam→"spam", 配合if __name__ == "__main__"区分 | 代价: 初学者易忘if块, 导入时意外执行代码

  SC3(边界): [归属困境: 接口隔离] from module import * 导入全部公开名字→污染当前空间 [隔离约束] → 选择: __all__ list显式声明公开API白名单(未定义则导除以_开头的所有名字) | 代价: __all__与代码不同步时混乱

【结构】"它长什么样？" {★★★}
- PyModuleObject: {md_dict(名字空间dict), md_name}
- sys.modules: {module_name→module_object} 全局缓存
- sys.path: list of str 搜索目录
- 包: __init__.py绝对/相对导入支持

【时序】"它按什么顺序动？" {★★}
- import X: 查sys.modules→sys.path搜→创建模块→入sys.modules→执行字节码→填充__dict__
- from X import Y: 先import X→将X.Y绑定到当前名字空间
- 循环导入: A→B→A, A在sys.modules中但不完整→B只能看到A部分属性

【实体】"它的最小数据单元？" {★}
- module.__dict__: PyDictObject (名字→对象映射)

【边界】"它在哪里交出控制权？" {★}
- 导入钩子: sys.meta_path自定义加载逻辑(支持zip/db包)
- sys.path搜索: 依赖文件系统→PermissionError/FileNotFound
- 相对导入: from . import sub 仅包内可用(需__package__)

【内部关联】
- import --[触发(查找→sys.path)]--> 文件系统搜索
- import --[触发(缓存→sys.modules)]--> 首次加载后缓存
- module.__dict__ --[使用(名字空间→名字绑定)]--> 所有模块级变量/函数/类
- __name__ --[触发(检查→入口判断)]--> "__main__" vs modname
- __all__ --[使用(白名单→from *)]--> 公开接口列表

【示例】
```python
import sys
print(sys.modules.keys())  # 已加载模块

if __name__ == "__main__":
    print("run as script")
elif __name__ == "mymod":
    print("imported as mymod")

# 包结构: pkg/__init__.py + pkg/sub.py
# __init__.py中: from . import sub  # 相对导入
```
