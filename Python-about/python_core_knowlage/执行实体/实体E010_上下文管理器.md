# 执行实体: 上下文管理器

> Step 4 | N6→D7 | 突破维度: 时序

【定义】 上下文管理器是实现__enter__/__exit__的对象, with语句保证进入时获取资源、退出时无条件释放(即使异常打断), 是Python版RAII。

【冲突溯源】 N6→D7(上下文管理器协议: 利用异常机制保障资源确定性释放——with=try/finally语法糖), 突破维度: 时序

【设计内因】 D7工程目标: 在异常随时可能打断执行的约束下, 保证资源(文件句柄/锁/网络连接)一定释放, 不依赖开发者手动记住close。
  通用困境:
  - (时序) 异常后资源release: 异常打断→手写close可能在异常路径被跳过
  - (时序) 异常传播vs抑制: __exit__捕获异常后需决策冒泡或吞掉

  SC1(时序): [归属困境: 异常后资源release] try{open; work} finally{close} 需开发者每次手写finally [确定性释放约束] → 选择: with obj as v: 编译为cm=obj; v=cm.__enter__(); try{body} finally{cm.__exit__(exc,val,tb)} [异常安全获取-释放] | 代价: __enter__若自身异常→__exit__不调用(无资源释放, 合理); 嵌套with退出为LIFO

  SC2(时序): [归属困境: 异常传播vs抑制] __exit__捕获异常后有3选项: propagate/抑制/换新异常 [异常决策约束] → 选择: __exit__返回True吞异常(抑制传播), 返回False继续传播; contextlib.suppress吞特定类型异常 | 代价: 误吞异常隐藏bug(但需显式返回True, 责任清晰)

【结构】"它长什么样？" {★★}
- 鸭子协议: __enter__()+__exit__(self, exc_type, exc_val, exc_tb) 不必继承
- contextlib.contextmanager: 生成器→上下文管理器(yield前=__enter__, yield后=__exit__)
- with A() as a, B() as b: 多嵌套(Python 3.1+)

【时序】"它按什么顺序动？" {★★★}
- with expr as var:
  1. cm = expr
  2. var = cm.__enter__()
  3. 执行 body
  4. cm.__exit__(exc, val, tb)  ← 无论3成功or异常都执行
  5. __exit__返回True→吞异常 / False→继续传播
- 嵌套退出: 后进先出(LIFO)

【实体】"它的最小数据单元？" {★}
- 鸭子类型: 无固定实体, 有__enter__+__exit__即满足协议
- contextlib._GeneratorContextManager: 包装生成器

【边界】"它在哪里交出控制权？" {★}
- __exit__抛新异常: 替换原异常
- async with: __aenter__/__aexit__ (配合asyncio)
- __exit__返回True: 异常被吞→不再冒泡

【内部关联】
- with --[触发(进入→资源)]--> cm.__enter__()
- with结束 --[触发(退出→释放)]--> cm.__exit__(exc, val, tb) [LIFO]
- cm.__exit__返回True --[触发(抑制→吞异常)]--> 异常不传播
- contextlib.contextmanager --[使用(生成器→协议)]--> yield前=enter, yield后=exit

【示例】
```python
class Trace:
    def __enter__(self): print(">"); return self
    def __exit__(self, *a): print("<"); return False

with Trace():
    print("work")   # > work <

# open()自动关闭
with open("f.txt", "w") as f:
    f.write("data")  # f自动close(即使write异常)

# contextlib
from contextlib import contextmanager
@contextmanager
def temp():
    print("start")
    try: yield "val"
    finally: print("end")

with temp() as v:
    print(v)        # start val end
```
