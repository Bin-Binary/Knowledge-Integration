# 执行实体: 基本数据类型

> Step 4 | N0→D1 + N3→D4 | 突破维度: 实体

---

╔═══════════════════════════════════════════════════════════╗
║  【数据类型】int / float / str / bool / None / bytes       ║
║  编号: E002 | 来源: C010-C025                            ║
╚═══════════════════════════════════════════════════════════╝

【定义】 Python内置不可变基本类型, 覆盖数值(int/float/complex/bool)、文本(str)、二进制(bytes/bytearray)、空值(None), 是编程中最频繁使用的数据单元。

【冲突溯源】 N0→D1(一切皆对象: int也是PyObject) + N3→D4(小对象缓存: 小整数池/字符串驻留/None单例), 突破维度: 实体

【设计内因】 D1+D4工程目标: 在"一切皆对象"的约束下, 让基础类型兼顾使用便利性(nice API)和内存效率(避免为每个0/1/"hello"分配新内存)。
  通用困境:
  - (实体) 高频小对象创建: 循环中每次i++创建新int → 数千次malloc/free
  - (实体) 变长字符串存储: Unicode码点1~4字节, 固定用4字节浪费空间

  SC1(实体): [归属困境: 高频小对象] for i in range(1000) → 每次创建新int → 若每次malloc/free触发数千次系统调用 [内存分配风暴约束] → 选择: 小整数池[-5,256]预分配→PyLong_FromLong直接返回缓存; None/True/False/()为全局单例; 短标识符字符串自动驻留(intern) | 代价: 池化对象永不释放; 长字符串intern需手动

  SC2(实体): [归属困境: 字符串变长存储] 如"hello"×10^6(纯ASCII)若按4字节/字符存储→浪费75%空间 [内存效率约束] → 选择: PEP 393灵活字符串: 根据最大码点自动选1/2/4字节kind, 数据紧跟在结构体后(compact) | 代价: 追加/拼接若kind升级需重新全量分配+转换

  SC3(实体): [归属困境: 布尔值类型] True/False需作为条件判断的明确值, 但创建独立类型违背A1简约性 [类型简洁约束] → 选择: bool是int子类(True=1,False=0), 全局单例 | 代价: isinstance(True,int)==True在某些类型检查场景引起意外

【结构】"它长什么样？" {★★}
- int: PyLongObject {ob_size(含符号), ob_digit[](30-bit数组)} 支持任意精度
- float: PyFloatObject {ob_fval(C double)} IEEE 754 64-bit
- str: 三态(PyASCII/PyCompact/PyUnicode) kind自适应
- bool: int子类, True/False单例
- bytes: PyBytesObject {ob_sval[] (0-255)}

【时序】"它按什么顺序动？" {★}
- int运算: 新对象创建(不可变), 大数O(n²)
- str拼接: 计算总长→分配→逐字符→返回新str
- str编解码: 遍历码点→codecs→OS编码器

【实体】"它的最小数据单元？" {★★★}
- int: ob_digit数组(uint30), ob_size带符号
- float: ob_fval(8 bytes)
- str: kind(1/2/4字节/字符), length, compact数据区
- None: 单例, sizeof(PyObject)=16 bytes, 仅头部

【边界】"它在哪里交出控制权？" {★}
- int运算: 不会溢出, 自动扩容仅受内存限制
- str编解码失败: UnicodeError异常
- float: CPU FPU计算, 精度由IEEE 754决定

【内部关联】
- int(256).ob_type --[配对(实→类型)]--> PyLong_Type (小整数池不创建新对象)
- str.encode() --[使用(文本→codecs)]--> codecs C编码器 → 系统调用
- bool --[使用(子类→父类)]--> int (继承关系)
- None --[使用(单例→每个不返回的函数)]--> return隐式
- bytes.decode() --[配对(二进制↔文本)]--> str.encode()

【示例】
```python
a = 5; b = 5
print(a is b)    # True (小整数池)
a = 257; b = 257
print(a is b)    # False

print(10**100)   # 一百位数字, 不溢出

s = "hello" * 1_000_000  # ~1MB (1字节/字符, 灵活存储)
print(type(True))         # <class 'bool'>
print(True + 1)           # 2
```
