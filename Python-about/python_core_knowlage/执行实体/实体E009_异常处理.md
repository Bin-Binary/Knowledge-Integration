# 执行实体: 异常处理

> Step 4 | N1→D2 | 突破维度: 实体

---

╔═══════════════════════════════════════════════════════════╗
║  【异常机制】try / except / raise / 异常层次体系            ║
║  编号: E009 | 来源: C090-C093                            ║
╚═══════════════════════════════════════════════════════════╝

【定义】 异常是运行时错误信号, 沿调用栈向上传播至except捕获; 异常按继承层次(baseException→Exception→具体异常)组织, 支持精确/宽泛两级匹配。

【冲突溯源】 N1→D2(异常层次结构: 用继承分类组织错误类型, 替代错误码实现精确/宽泛两极匹配), 突破维度: 实体

【设计内因】 D2工程目标: 用异常层次结构(实体)替代C风格错误码, 将错误处理从正常控制流分离; 用栈展开(时序)实现自动向上传播。
  通用困境:
  - (实体) 错误分类粒度: 太细→Exception子类爆炸; 太粗→用Exception捕获丢失信息
  - (时序) 多层错误传播: 深度嵌套(A→B→C)中C出错, 逐层返回错误码→代码路径爆炸

  SC1(实体): [归属困境: 错误分类粒度] 需同时支持"精确捕获ValueError"和"宽泛捕获Exception"两级粒度 [分级分类约束] → 选择: BaseException→Exception→(ValueError/TypeError/KeyError/…/UserException)—except按isinstance(exp, exc_type)匹配, 多条except顺序测试[层次化匹配] | 代价: except Exception不获取SystemExit/KeyboardInterrupt(这是正确行为); 用户自定义异常需正确选父类

  SC2(时序): [归属困境: 多层错误传播] 深度调用链中若每层检查+传递错误码→代码膨胀 [分离错误与正常流约束] → 选择: raise→栈展开: 从出错帧逐层弹栈→找匹配except→未找到则上帧继续→栈顶→sys.excepthook→进程退出 [自动向上传播] | 代价: finally在展开中执行(可能覆盖异常); 异常传播代价高于返回码

  SC3(时序): [归属困境: 资源清理] 异常打断正常→已获取资源(文件句柄/锁)必须释放 [资源安全约束] → 选择: finally块(无论是否异常/return/break都执行) + with语句(上下文管理器自动clean) [异常安全清理] | 代价: finally中return/break吞掉异常

【结构】"它长什么样？" {★★★}
- 异常层次: BaseException←SystemExit/KeyboardInterrupt/GeneratorExit←Exception←(ValueError/TypeError/KeyError/OError/…)
- except匹配: isinstance(obj, exc_type) → 多条except顺序测试(首次命中)
- raise from: __cause__(显式链) + __context__(隐式链)

【时序】"它按什么顺序动？" {★★}
- raise exc: 创建异常→设traceback→展开: 当前帧except→匹配则bind→执行except体→finally→else(无异常时)
- 未匹配: 弹帧→上帧重复→栈顶→sys.excepthook→traceback打印→exit
- except…as e: e绑定→except块结束后e引用清除(防止循环引用)
- raise(无参): except中重新抛出当前异常(保留原traceback)
- finally: 无论如何执行(在除exit之外的任何访问)

【实体】"它的最小数据单元？" {★★★}
- BaseException: {args(tuple), __traceback__, __cause__(显示链), __context__(隐式链), __suppress_context__}
- traceback对象: tb_frame→tb_lineno→tb_next(栈帧链表, 最内向外)

【边界】"它在哪里交出控制权？" {★}
- raise from Y: __cause__=Y, 异常链追踪
- finally中raise: 替换但不覆盖原异常
- 无matched except: 进程exit

【内部关联】
- raise --[触发(异常→传播)]--> 栈帧展开链(tb_frame链表)
- except --[触发(捕获→isinstance匹配)]--> exc_type层次
- finally --[配对(无论如何→执行)]--> try块结束/异常/return/break
- exc.__traceback__ --[使用(异常→来源溯源)]--> tb_frame链

【示例】
```python
try:
    x = 1/0
except ZeroDivisionError as e:
    raise ValueError("Invalid") from e
finally:
    print("Cleanup")  # 始终执行

# 异常链
try:
    raise TypeError("type err")
except TypeError as e:
    raise RuntimeError("wrap") from e  # __cause__ set
```
