## 按认知层次检索 (广度优先学习路线)

```
L0: 对象模型 ──→ 了解 Python 的世界观
L1: 基本类型 ──→ 掌握数据原子单元
L2: 复合类型 ──→ 用容器组织数据
L3: 控制流   ──→ 让程序按你想要的路径走
L4: 函数作用域 ──→ 封装与复用代码
L5: 迭代生成 ──→ 惰性处理大数据的正确姿势
L6: 面向对象 ──→ 用类组织复杂的现实世界
L7: 模块包   ──→ 从单文件到专业项目
L8: 异常处理 ──→ 写健壮的、能优雅失败的程序
L9: 文件I/O ──→ 与外部世界交互
L10: 高级特性 ──→ 用装饰器、注解写出优雅代码
L11: 内存执行 ──→ 理解底层, 理解为什么性能这样
```
