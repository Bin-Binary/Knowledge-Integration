## 测试类型说明

| Skill 类型 | 对应测试类型 | 观察重点 |
|-----------|-------------|---------|
| **Technique** | Application + Variation + Missing Info | 能否正确应用方法步骤？边界场景是否覆盖？指令是否有缺口？ |
| **Pattern** | Recognition + Application + Counter-example | 能否识别何时适用？何时不宜用？能否使用思维模型？ |
| **Reference** | Retrieval + Application + Gap | 能否找到正确信息？能否正确使用？常见用例是否覆盖？ |
